# Phase 2C 验收报告

本阶段完成棋盘视觉与热座操作调整，不进入 Phase 3/4。

## 棋盘

已确认上一版接入了Token，但旧CSS对所有嵌套SVG设100%尺寸，破坏了道具与头像的实际显示；现只约束最外层SVG。道具直接展示现有原创PNG及引擎状态，未翻开时显示四色类别背面；修好的发电机移离原槽。角色使用剪影头像及伤环、搬运/挂钩状态；公共棋盘继续隐藏储物柜内的身份。

移动牌及日志统一为潜行（蓝）、冲刺（绿）、蹲伏（红）、翻越（黄）、等待，牌面和路线共用原创动作剪影。每个物理路线ID显示一个方框，废车场两处三房间共享路线各保留一个共用图标及三条分支；箭头与墙壁锯齿按现有数据绘制，合法路线和动作方框同时发光。

21个真实房间各有一张原创场景，原生1536×1024；本次使用内置image_gen逐张生成，没有输入官方美术作为参考。房间名、1–5刻痕、原创杀手出生头像、道具及角色均为动态叠加。素材和实际提示登记在manifest.rooms与PHASE_2C_ART_PROMPTS；道具/头像仍保留PNG缺图SVG回退，房间缺图保留原创代码场景底图。

顶部为8个钩子图案、4台发电机和1个出口大门；深色划痕背景由代码绘制。技能检定骰为黑色立体骰，危险骰为红色；叉/勾/星区分结果，成功骰面保留真实数字，滚动继续遵循动画开关。

## 手机与操作

默认铺满可用宽度、显示可读的局部地图，支持全图、房间定位、当前角色定位、双指缩放和拖动。竖屏切横屏采用软件旋转，指针坐标同步转换；原生横屏也可操作。全图供总览，局部用于看清房间和道具。

开局翻道具不再列长按钮；直接点击亮框六边形。交互点击对应道具或角色；同一目标有多种合法操作时，再显示该目标的选项。健康棋子另加明确点击区域，修复点击透明美术时穿透到房间的问题。界面只调用原有合法操作查询与命令，不自行结算。
