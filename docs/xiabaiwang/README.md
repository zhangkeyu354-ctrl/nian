# 瞎掰王 · 深夜胡扯电台 UI v1

执行依据：[用户v2指令](../instructions/XB_UI_V1_2026-10-23.md)。分支 `codex/xiabaiwang`，供复验，不合并main、不部署。

## 本地预览

`http://127.0.0.1:3358/?game=xb`；独立房间数据位于 `output/xb-ui-v1/rooms`。也可用 `PORT`、`DBD_DATA_DIR`、`XB_DATA_DIR` 配置自己的本地服务。

## 已实现

- 原创大嘴喇叭、可爱粑粑SVG；深墨蓝配番茄红、芥末黄、薄荷绿、紫色，暖白便签题卡。按钮样式只作用于XB，没有改全站button。
- 56px顶栏、单阶段舞台、座位区、52px主按钮与最多两个次按钮；横屏左舞台、右座位/操作。十人长名字视觉省略，完整名称保留在可访问标签。
- 身份翻牌0.6秒，3秒收起，可再查看；语音自由讨论，不加文字解释卡或发言稿。选头像后点两次主按钮确认；服务器回应前锁重复提交。
- 按座位每900ms翻身份，真假配章和文字，飞分进入头像、分数条和名次换位。3/6/10人揭晓分别6/7.4/11秒；可跳过，减少动态偏好直接显示结果。
- 粑粑抛物线、命中压扁、目标震动请求，前后端禁止扔自己；无限次、每人2秒冷却。娱乐事件聚合，统计单独保存到 `.fun.json`，不写规则状态、不改变分数。
- 2秒轮换横幅、领奖台、三个趣味称号、每轮回顾、房主再来一局。称号只读公开历史和娱乐统计，无额外积分，支持并列。
- XB音效默认开，复用drawing/feel.ts合成器，新增可选偏好参数而不改旧调用行为。XB音效、震动、动画独立关闭，不改绘画派对设置。震动需设备支持，自动化只证明API请求，实机仍需复验。
- 昵称、房间号、公开选人草稿保存在本设备，断线不丢、不自动提交；私人答案不存入浏览器存储。
- 原创题库64题：简单17、中等23、困难24。新增48题独立编写，逐题核对NASA/NOAA事实来源；难度为本项目编辑分级，非原版卡牌难度。

## 等待裁定

`packages/xiabaiwang/src/engine.ts` 与上一提交 `efab4d2` 完全一致。基础计分、初始分、负分下限、总轮数、质疑叠加仍待用户核对，不称官方规则。

房主轮数控件显示当前“每人一次”并禁用，注明待裁定。180秒圆环只是讨论参考，超时不扣分、不自动结束或切阶段。粑粑显示∞，不添加有限弹药。领奖台按分数和入座顺序稳定显示，不新增同分决胜规则。

## 验收证据

- `npm test -- --testTimeout=20000`：43个测试文件、807项通过。旧隐私回放在繁忙机器上可能超过默认5秒，使用20秒上限；未改变既有断言。
- `typecheck`、`build`、`verify:replays` 通过。
- `npm run verify:xb-browsers`：3/6/10人完整浏览器整局通过，含断线草稿、刷新、秘密投影、禁言、拒绝扔自己、并发娱乐、跳过揭晓、减少动态偏好和再来一局。支持 `XB_TEST_URL`、`XB_PLAYER_COUNTS`，兼容旧人数范围变量。
- `npx tsx scripts/verify-xb-feedback.ts`：本机Chromium首反馈帧约1.3ms，按下缩放0.96；不代表所有真机的延迟。
- 主要文字配色对比度：行动按钮5.59:1、辅助文字9.19:1、真话章6.40:1、瞎掰章7.13:1、便签正文8.49:1。禁用操作使用灰态，身份从不只用颜色表达。
- [截图与报告](ui-v1/) 包含390×844和844×390各阶段、揭晓三时刻、粑粑、终局、断线条，以及十人长昵称和十人揭晓。脚本检查无页面横向溢出，扫描64个答案均未进入浏览器打包产物。
- 五款旧游戏的回归结果见 [交接](../handoff/XB_UI_V1_交接_2026-10-24.md)。所有操作在本地独立数据进行。

## 复验重点

真实手机音频解锁、震动兼容、长名字和横屏舞台滚动；快速跳过与切换下一轮；被禁言者继续互动；断线恢复公开目标；计分与轮数裁定。交复验者确认后再决定合并上线，本轮不推送、不部署。
