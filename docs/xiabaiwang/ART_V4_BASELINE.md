# 美术 v4 执行基线

已批准的现有产品美术迭代；沿用已有产品验证、PRD、对齐和流程基线。用户明确要求实现，按 approved-implementation / tdd-builder 执行，不重新开启新产品立项。

- 视觉主张：一盏暖灯照着二维卡通录音室，暗色调音台承载操作，节目稿纸是唯一内容焦点；与请留遗言统一光源、绘画派对的材质秩序对齐。
- 内容层次：顶栏频道／直播灯；舞台题目或身份；金属底座角色座位；拇指区单一主操作。等待、闭眼、回放、终局沿用原阶段和可达路径。
- 交互主张：发言时才显示声波环；卡带正反翻面；揭晓保留原时间轴，材质与头像替换，减少无意义装饰。
- 场景和十动物由内置image_gen原创生成，按用户后续要求统一二维卡通线条、夸张造型、赛璐璐明暗、暖左光与冷色环境光；WebP高低清＋预模糊版本。字体用OFL站酷小薇体子集并附许可证；其他画面素材不取用外部IP。
- 本轮按XB_FINISH补完原版流程与用户追加换词；引擎只调整解释队列及换词，计分规则和题库与6ed7f74保持一致。美术恢复自aa5767e时期stash，未恢复旧截图。
- 所有运行美术素材合计也控制在1.5MB内，强于首屏预算；头像非首屏加载，非当前游戏不请求场景或字体。低配置／省电／减少动态使用预模糊图且关闭实时滤镜。
- 测试先覆盖素材预算和降级策略；真实浏览器取八关键阶段双尺寸及同尺寸参考游戏并排对比。原测试入口保留，只修正呼吸按钮的自动等待和新引导适配。
