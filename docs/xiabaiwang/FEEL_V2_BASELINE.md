# 手感 v2 执行基线

用户直接批准的既有游戏迭代，依据 `docs/instructions/XB_FEEL_V2_2026-10-24.md`。继承已完成的 STAR、PRD、对齐和 UI v1 基线；本次只扩展手感、题库和主题抽取，不重新建设平台。

视觉主旨：纸质深夜电台，让按压回弹、翻身份盖章和抛物线命中成为三个主节奏。信息仍按顶栏、单阶段舞台、座位、行动栏组织。主动作保持可读，粒子和声效不阻塞操作。

- 小动作150/180ms ease-out；身份翻转800ms使用指定回弹曲线；只以transform/opacity驱动特效帧，发光采用静态阴影层的透明度变化。
- 省电模式跟随系统减少动态强制开启，也可独立选择；关闭粒子、移动、旋转、抖屏，静态结果和必要淡入仍可读。跳过直接显最终状态，不逐张重播。
- 触摸音效统一走XB feel模块，复用drawing音频底层且不改其旧调用。震动仅轮到自己、自己被击中和自身分数变化；B节明确的长按确认10ms为用户指定例外。
- 保留双击确认，也提供500ms长按；中途松手不发送命令。抑制长按/拖拽合成click的标记必须在该次手势结束清除，不吞掉后续独立点击。
- 计时仍为参考，不到时强制换阶段或改分。等待、超时、拒绝原因均中文；网络锁和断线草稿沿用v1。
- 娱乐动画和连击、贴纸仅客户端表现；命中统计沿用独立fun文件，不进规则状态。拖拽与点选调用同一服务端poop事件，统一2秒冷却和非自身校验。
- 主题可多选或全部随机；设置由房主在大厅修改。旧64题仍可通过全部随机抽到，新96题归入12个主题，每主题8题。可用题少于本局人数时明确拒绝开局，提示增加主题；不偷偷重复已出题。
- usedTopics随房间存档，跨刷新、重启和再来一局保留；旧存档在再来一局时从历史补齐。引擎仅增加可注入题库参数及容量检查，计分、初始分、轮数和身份算法不改。
- 验收包括行为测试、真实3/6/10人、原五游戏、竖屏截图和真实Chromium Performance trace；桌面帧率不能替代所有手机的硬件表现。

用户后续贴来的原版计分整理另存为规则待执行记录。本指令仍冻结计分；不推送、不合并main、不部署。
