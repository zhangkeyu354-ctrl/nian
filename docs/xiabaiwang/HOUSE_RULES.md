# 瞎掰王房规

用户于2026-10-24明确裁定；以下为线上版选择，不能表述为台湾原版全部如此。以[计分核对表](CHECK_REQUIRED.md)区分第三方规则介绍与用户裁定。

| 编号 | 房规 | 原版资料边界 |
|---|---|---|
| HR-XB-01 | 支持3～10人；10人为线上扩展，仍为1名想想、1名老实人，其余瞎掰人。 | 台湾繁体版上限9人。 |
| HR-XB-02 | 想想每轮最多一次「你在放屁！」（公三小）。仅讨论时可用，不能撤回；禁言不淘汰、不揭身份，仍可被指认或扔粑粑。 | 公开介绍对每轮卡数不一致；本项目明确选一次。 |
| HR-XB-03 | 可以负分，没有下限。 | 公开整理未明确负分下限；本项由用户决定。 |

初始每人3分。质疑与指认分相加，不因同一个目标而抵消结算步骤。计分详情见CHECK_REQUIRED.md。

另有用户确定的对局设置：默认一圈，每人一次想想；房主可设两圈。按座位顺序向左传递，第二圈从第一个座位继续。两圈需有足够未出题目，开局前由服务器检查。最高分共同获胜；相同分数共享同一级领奖台，后续不同分数依次为下一等级（稠密名次）。

扔粑粑是原创娱乐互动，完全不计分；其统计只用于娱乐称号。
