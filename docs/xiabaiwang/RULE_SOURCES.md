## 原版流程与地区差异

- B级：[台版发行方狗吠火车的募资说明](https://www.zeczec.com/projects/TW-9upper)。公开说明和步骤图确认猜测者、秘密老实人、瞎掰人、老实人看答案及「公三小」机制；公开文字没有完整计分数值，不据此声称公式已获官方确认。步骤图仅下载到被忽略的 output 目录作核对，不进入站点或Git。
- D级：[龐奇桌游规则介绍](https://punchboardgame.blogspot.com/2023/06/9-upper-by.html)、[玩家规则整理](https://euddedehi.blogspot.com/2022/12/9upper.html)描述猜中双方按难度得分、猜错被选者得分；仅作候选公式线索，不升级为官方资料。
- [独立线上版](https://9upper-online.com/how-to-play)不是原版发行方，不能作为官方规则确认。
- U级：用户2026-10-23明确指定质疑得分：命中瞎掰人 +1/-1；误中老实人 -3；禁言不揭身份且仍可被指认。按用户指定实现，规则页面写明地区版参考及本线上所选玩法。
- U级：3～10人、扔粑粑无规则影响、自由讨论、外部语音，均按用户范围。
- 线上回合安排：每位玩家按加入顺序任一次猜测者为一局，初始0分。此为当前开发方案，不宣称原版人数对应回合数。
- **CHECK_REQUIRED**：基础计分尚缺原版规则书或发行方明确数值原文。开发候选为猜中双方+D、猜错被选者+D，已在界面标注待核；生产发布与最终规则验收前须核定。

## 原创题库

2026-10-24已从16题扩到64题（简单17、中等23、困难24），中文题面与释义独立编写，不抄商业卡牌。难度1～3为编辑分级。逐题来源在服务端 `topics.ts` 与新增 `topics-v1.ts`：新增48题核对NASA八个天体事实页、NOAA十二个海洋科普页，原16题来源保留。公开前仅当前题目发全员，答案和出处仅发老实人；揭晓后写入公开历史。浏览器不导入题库或随机种子。

## 运行与验收

- `npm run build`
- `npm test -- --testTimeout=20000`
- `npm run typecheck`（先按仓库流程生成 `apps/web/test/scenarios.generated.json`）
- `npm run verify:xb-browsers`，需先启动本地服务；默认 `http://127.0.0.1:3348`，可用 `XB_TEST_URL` 指定。
- 预览入口：`/?game=xb`，房间链接：`/?game=xb&room=XXXXXX`。
- 存档：`XB_DATA_DIR`；沿用现有原子JSON房间文件模式。Render免费实例磁盘的长期保留能力不在本功能中改变；已存文件时服务重启可恢复，平台丢弃临时磁盘时无法恢复。
- 仅独立分支本地开发；不推送main，不触发Render。
