# 第一版界面执行基线

依据用户明确批准的 `docs/instructions/XB_UI_V1_2026-10-23.md`；此前STAR/PRD/对齐已完成，此次为已授权视觉迭代。使用design-baseline、frontend-skill、tdd-builder。

视觉主旨：深墨蓝深夜电台，原创大嘴喇叭与暖白便签形成主视觉；红色只强调动作，黄/绿/紫对应分数/真话/瞎掰并配文字。内容依次为连接与轮次、单一阶段舞台、座位、拇指操作。动效以身份翻牌、揭晓盖章与分数换位、抛物线压扁反馈为主。

执行决定：

- 不改 `engine.ts` 任何计分和轮换公式。房主轮数设置展示现值并禁用，注明待裁定；不假装可用。
- 顶栏180秒参考计时仅展示讨论经过时长，不强制换阶段或扣分；服务器只保存讨论开始时间用于刷新一致。
- 粑粑仍无限次、每玩家2秒冷却，按钮显示∞；前后端均拒绝自己作为目标。娱乐被扔次数独立保存，不写规则状态，不成为计分。
- 发身份、轮换和逐人揭晓均为视图子阶段，不加文字答案提交。揭晓6～12秒且随时可跳过；减少动态偏好直接显示结果。
- 使用 drawing/feel.ts 的声音合成器，扩展可选音画偏好参数，默认调用语义保持，其他游戏行为不变。XB声音、震动、动画各自可关闭；不修改绘画派对的全局声音设置。
- 终局趣味称号由已揭晓历史和独立娱乐统计导出，允许并列，无数据则明确无人；不加规则分数。再来一局由房主把已结束房间返回大厅，重新开局沿用现有初始分逻辑。
- 用户输入昵称、房间号、公开目标草稿保留到本机，断线不丢；不保存私人答案到浏览器存储。请求立即反馈并锁重复提交；拒绝给中文原因及动作区抖动。
- 固定四区用100dvh和内部滚动，不产生页面横向溢出；10人座位折为两排，保留完整名字的可访问标签。横屏左舞台右座位/操作。所有样式作用域xb-world，按钮44px起，主按钮52px，题目28px起，正文17px起。
- 关键状态：入口、入座、大厅、发身份、讨论、质疑、指认、揭晓三时刻、计分、轮换、终局、重连；两种尺寸真实截图。全部功能完成后复验3/6/10人及原五游戏；本分支提交，不推送不部署，交用户安排复验。

对齐：用户已明确指定不加解释卡、计分等待裁定，以上不新增游戏规则。可以实施。
