# 瞎掰王基础功能开发与验收

日期：2026-10-23。分支 `codex/xiabaiwang`，基线 `c9f088f`。未修改或推送生产main，未部署。

## 已实现

原大厅新增入口 `/?game=xb`；原Node/Socket.IO服务器挂载 `xb:*` 事件。按现有每游戏房间模块模式实现token座位、个性化快照、原子JSON保存和恢复。新增独立纯规则引擎，不修改任何既有游戏规则引擎。

3～10人，一猜测者一老实人、其余瞎掰人；自由讨论、可自愿标记发言；猜测者质疑、最终指认、公开结算、历史分差、顺序轮换及最终排名。首批16道原创编写的题面和释义，逐题记录事实来源，难度为编辑分级。

质疑严格验证操作者、阶段、回合和一次性；不提前公开目标角色，目标仍在座且可被最终指认。用户指定+1/-1/-3在揭晓时和基础分一起结算。

娱乐独立事件，仅发送公开玩家ID和次数，每玩家2秒冷却；120ms聚合广播，每批最多10个动画，同屏最多20个。限流与规则事件独立，不写规则状态、事件版本或分数。禁言者仍能使用，支持关闭动画与音效，减少动态偏好自动关闭动画。音效默认关。

基础手机UI有题目、猜测者、当前自愿发言者、全员头像、隐私角色、固定操作区、目标选择、不可撤销确认、全员禁言提示、历史和排名。确认框支持Escape、焦点循环，按钮44px起。具体视觉与美术待用户后续指令。

首轮全量测试在默认5秒超时下有一项旧隐私回放超时；20秒上限复跑799项全通过。随后新增娱乐限流独立性回归测试，最终 `npm test -- --testTimeout=20000` 为 **39个测试文件、800项全部通过**，用时297.95秒。类型检查、构建及全部16题答案不进入浏览器产物的扫描通过。早期旧浏览器脚本和页面预热有等待失败，以上“通过”来自后续实跑，不将早期失败抹去。

## 尚未最终验收的项目

- 基础计分原版完整数值依据仍待核，界面和来源文档明确标记；当前公式是开发候选，不能称官方计分。
- UI和美术风格等待用户进一步指令；目前是可操作的基础界面。
- 首批16题可满足十人完整一局，长期重复游玩需要继续扩题。
- 未做外网/真实手机性能验收，未接入语音；禁言依赖玩家遵守外部语音约定。
- 持久化沿用现有项目磁盘能力；存档可读时可跨服务重启恢复，未改变Render免费实例的临时磁盘限制。
