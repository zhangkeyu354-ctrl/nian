## 界面与引擎

- React、TypeScript、Vite和Tailwind实现全中文界面，沿用“杀手”“厄咒图腾”“出口大门”等实物用语。可选两张地图和13名基础角色，支持3–5人兼控。
- 棋盘由MAP_DATA及当前引擎状态生成SVG房间、彩色路线、单向箭头、锯齿墙框、44道具槽位、角色与配件、献祭及发电机进度。独立layout.json只负责示意位置和折线控制点，不决定房间连接或规则；没有背景棋盘图片，也不复制原版美术。
- 引擎新增只读查询：当前操作者、合法操作、合法路线预览、公开道具、搬运路线延伸和技能参数。按钮提交给既有reduce；前端不结算随机数、伤害、移动阻挡、费用或胜负。
- 角色面板显示移动牌、血点/健康/物品、板载技能全文与消耗，杀手力量和被动可查。房间/道具可直接点选，歧义时由下方操作列表选择。
- 每次出生骰/检定逐次显示结果，确认后继续；中文事件日志及全部掷骰记录可回查。下一位玩家接手时移除棋盘、手牌及参数DOM并显示遮挡。
- 手机390×844竖屏通过：双指缩放、单指拖动、缩放复位按钮，无页面横向溢出；普通按钮至少44px，地图小目标另有大按钮入口。
- CHECK_REQUIRED显示“该功能尚未实现”，拒绝操作不改变状态。既有34个板载技能及6个力量保持引擎支持；五项延后技能和物品效果仍留Phase 4，未伪装为已实现。
