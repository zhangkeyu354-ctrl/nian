# Phase 2C 棋盘视觉与交互基线

用户明确授权本阶段，保持热座模式；不进入 Phase 3/4，不修改规则计算、地图拓扑、数值或随机数。

视觉方向：煤灰、旧金属与薄雾；原创房间场景为主体，彩色动作方框连接房间，六边形道具与剪影棋子叠加其上。桌面完整地图，手机默认可读局部并可全图/定位/缩放/横屏查看。

信息顺序：顶部图案进度轨 → 地图及当前可点道具 → 移动牌与操作面板 → 事件日志。路线图标与线条一起高亮；动作文字为潜行（蓝）、冲刺（绿）、蹲伏（红）、翻越（黄）、等待。

交互：开局道具与交互目标直接点击棋盘；选择有多种合法操作的目标后才显示该目标的按钮。仅从引擎查询合法操作，再发送原有命令。拖动、双指缩放、全图和定位只改变视图。

手机默认放大到房间文字、图标可读的局部。全图用于总览，不声称全图状态仍可看清每个图标。横屏按钮打开棋盘专注视图；支持设备原生转横屏。竖屏点击横屏时，以 CSS 旋转整个棋盘专注视图，并相应转换拖动坐标；不依赖浏览器方向锁定权限。

保密：躲藏者继续不出现在公共棋盘，柜子仅显示被占用；匿名隐藏棋子状态在样本页可见，不把身份泄漏到公共格子。

美术：21 张原创场景，一房一图，不把官方图作为生图参考；沿用已有32张原创道具与头像。动作剪影由代码原创绘制。原版照片只用于用户要求的本地并排对比，不入库、不进入交付源码包。

验收：两地图各有电脑1440×1100、手机390×844、横屏844×390实际中局截图；每条路线恰有一个动作方框，三房间共享图标连出三条分支；验证点棋盘翻牌/交互、原牌名、图标PNG加载、触摸与遮挡；原回放结果不变。
