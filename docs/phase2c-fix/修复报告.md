# Phase 2C 修复报告（Claude 接手，2026-10-19）

Codex 因额度用完中断，本轮由 Claude 完成。规则引擎与游戏数据未改动。

## 1. 废车场电脑截图空白
- **原因**：在 Claude 的环境里按原脚本重放同一局，棋盘能正常显示。Windows 上那张空白截图，最可能是房间插画还没解码完就截了图。原验收脚本只检查截图文件和 DOM 元素存在，**没有检查截图里的像素**，所以空白也判定为通过。
- **修复**：新增 `scripts/screenshot-check.ts`，每张验收截图都要通过三项检查：
  1. 截图前等待所有棋盘图片解码完成；
  2. 统计**完整出现在棋盘视口和窗口内**的房间数、路线图标数（麦克米伦 11/22，废车场 10/19），数量不对即失败；
  3. 对截图像素做统计，棋盘区域内容太少或画面几乎纯色即判定"疑似空白"失败。
- 另修复一个 404 控制台错误（缺少网页图标），它会让验收脚本误报。

## 2. 手机横屏操作区太占地方
- 小屏幕（宽度 ≤ 950 或高度 ≤ 550）上，"查看房间"栏和图例默认收起，地图顶栏新增"图例"按钮可展开。
- 横屏时棋盘高度约为屏幕高度减去顶栏，远超 75%。

## 3. 房间名被遮挡 / 4. 图标重叠
- 定位视图四周留 40 单位安全边距，房间名不会贴边被裁。
- 有出生标记的房间，角色棋子整体右移，不再压住出生标记；超过 4 人时头像缩小。
- 道具点击区按槽位间距计算，相邻道具点击区不再重叠。

## 5. 手机默认视图
- "定位"改为自动缩放到**当前房间 + 全部相邻房间**（考虑三房间共用图标）。
- 手机上地图缩得很小时，第一次点房间或道具**只会放大到该房间**（防误触），放大后再点才执行操作；放大后道具点击区 ≥ 44×44 像素。
- "查看房间"列表在手机上直接放大到所选房间。
