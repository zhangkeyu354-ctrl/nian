# 原创美术与状态界面规范

Phase 2补充，2026-10-19。先完成引擎状态投影、SVG占位、动画与设置，再制作PNG；不进入Phase 3/4，不增加桌游规则。

## 视觉语言

黑暗迷雾中的做旧手绘剪纸：炭黑轮廓、骨白刻线、少量锈铜高光。道具统一六边形底框，轮廓用简洁的原创几何结构，不复制、描摹或参考官方图标、角色立绘、Logo；替换此前计数划痕式品牌装饰。角色是原创、非写实的肩部剪影，不尝试还原官方脸、面具、服饰或武器。中文名由HTML/SVG文字层独立排版，图片不烘焙文字。

四类背面：目标 objective 黄 #D8B95C；无惧 boldness 红 #BB6458；逃生 survival 蓝 #609CB7；援助 altruism 绿 #7DA579。颜色以外各有独立纹样和中文标签，不依赖颜色辨识。路线颜色仍按原地图数据，不与道具背面类别混用。

## 尺寸与背景

- 道具/背面/配件/标记：PNG统一原生1254×1254（界面按256规格缩放），透明RGBA，主体位于中央80%；代码SVG viewBox 0 0 128 128，可同比缩放。
- 原创角色剪影：PNG统一原生1254×1254（界面按384规格缩放），透明RGBA，头肩构图；中文名和受伤环/挂钩/搬运/疯狂等由独立状态层绘制。
- 原创品牌灯笼：SVG优先，128×128透明；不使用官方五划Logo。
- 不生成棋盘背景图、完整界面截图或带状态数值的美术。进度、占用、封锁、放倒等必须由引擎数据覆盖，防止素材与规则状态脱节。
- PNG解码失败、404或尚未生成时立刻使用随包SVG，占位与正式图相同尺寸，不出现空图标。全部资源本地保存；资源登记在assets/manifest.json，浏览器副本在apps/web/public/assets/manifest.json。

## 状态与隐私

引擎只读投影提供所有状态：房间、路线、进度轨、移除区分开。修好发电机从房间移到进度轨；被净化图腾、搜索后的箱子不再占据房间格；放倒木板在路线显示。已移除道具的原槽仅留空六边形。

储物柜仅显示“被占用”，不附躲藏者头像、姓名、ID或工具提示；公共棋盘不绘制躲藏角色。公开日志与储物柜检定结果同样匿名化。自己的私有角色操作面板仍属于本人。

所有状态变化只读引擎和其事件，不由动画改变规则。动画队列可在交接遮挡前显示公共动作；不包含秘密计划或躲藏者身份。状态一览是明确标注的展示样本，使用同一套组件，不可冒充真实对局记录。

## 动画

翻牌360ms、掷骰520ms、进度420ms、受伤360ms、挂钩600ms、净化/搜索/乌鸦移除420ms、胜利650ms。优先transform/opacity与短stroke过渡，不使用视频背景或持续粒子。一次最多8个反馈；进度条仅表示真实进度。

设置提供“启用动画”和“使用PNG美术”，保存在本设备。关闭动画或系统prefers-reduced-motion时，无旋转、缩放、闪红或位移；仍显示静态结果和状态，按钮可立即继续。手机不增加动画负担，不延长规则流程。

实际生成说明：工具请求1024方形，32份实际输出均为1254×1254透明RGBA；已统一登记真实尺寸，未裁切或改画生成图。SVG仍为128坐标系，PNG与SVG通过相同组件缩放。
