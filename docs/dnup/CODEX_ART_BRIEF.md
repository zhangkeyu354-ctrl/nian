# 反转王牌 Dnup：美术需求（给 Codex，2026-11-19）

先 `git pull origin main`。游戏已由 Claude 搭好并能整局联机：入口 `/?game=du`，前端 `apps/web/src/du/`（`Dnup.tsx`、`dnup.css`）。**你只负责美术和视觉，不改规则引擎 `packages/dnup/`、服务器 `apps/server/src/du-rooms.ts`、协议文件，也不改任何 `data-testid`。** 在分支 `codex/dnup-art` 上做，做完报告并停止，不合并、不部署。

## 风格
参照官方包装（用户发的截图）：黑底上大块、粗圆角的彩色数字笔画互相穿插；亮绿色主色带；白色粗体圆角 logo「dnup」（u 和 p 是 d 和 n 倒过来，体现“反转”）。整体要像高级的实体卡牌，**不要贴图感、不要像小程序**。用户主要用手机竖屏玩，每一项都要在 iPhone 13 竖屏截图检查。

## 要做的素材（放 `apps/web/public/assets/dnup/`，WebP，注意体积）
1. **牌面**：米白色卡纸质感底（细微纸纹、圆角、轻微厚度阴影）。目前代码用纯 CSS 画牌（大数字 + 左上角小数字 + 右下角倒着的另一端数字），保留这个结构，只换质感：可以做一张通用牌面底图，数字仍用文字渲染（这样 40 张牌不用各画一张）。数字字体换成粗圆角、接近原版的风格（可找免费可商用字体，自托管到 `public/assets/dnup/fonts/`）。10 个数字各一种颜色，参考原版：现有色表在 `Dnup.tsx` 的 `NUM_COLOR`，可调整。
2. **★ 星牌标记**、**人数点数**不用画（网页不显示）。
3. **桌面背景**：深色木纹桌面或深色毡布，竖屏、横屏各一张，暗而不抢牌。
4. **Logo**：「dnup / 反转王牌」标题图，用在大厅入口卡片（`GameLobby.tsx` 里 id="du" 那张，目前是 CSS 临时 logo）和游戏内房间页顶部。另做一张大厅封面图（参考包装的彩色数字穿插图案）。
5. **计分标记**：小圆形字母标记 d / n / u / p 四种图标（只是装饰，分数仍按数量显示），替换现在的「●」。
6. **动效与反馈**（CSS/JS 即可）：
   - 翻转整手时每张牌平面旋转 180°（现在已有简单动画 `du-spin`，做得更有手感，可依次错开）。
   - 被压回的牌飞回主人那里并旋转；拿走整组时牌飞到拿牌人。
   - 出完手牌：名次徽章（第 1 名金、第 2 名银）弹出。
   - 终局获胜画面要有庆祝感（彩色数字笔画飘落之类）。
   - 轮到自己时有明显但不刺眼的提示（可加轻微震动 `navigator.vibrate`，参照 `drawing/feel.ts`）。
7. 音效可选：出牌、翻转、压回、得分各一个短音效，音量要小（用户之前反映音效偏大），右上角可关。
