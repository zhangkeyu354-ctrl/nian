## 验证

- 390×844、360×740 的目标入口逐页截图和 DOM 测量：目标页面均无横向溢出；指定的点击热区达到至少 44×44px，指定功能文字至少 12px。
- 浏览器整局：犯罪现场 4 人、魔法运动员 2 人四场、遗言 4 人、行动代号两局 4 人、拉密 2/3/4 人、你画我猜与假画家 3 人流程均通过。脑洞量表 4/6/9 人整局及九人结算完整名单断言通过，报告 200 张截图、200 次布局检查、0 条页面错误。黎明杀机两个种子的 5 人对局均通过，分别为杀手胜和幸存者胜。
- `npm test`：148 个文件通过、1 个跳过；1840 个测试通过、1 个跳过。`npm run typecheck`、`npm run build` 通过。构建仍有原有的 `dying-message-original/table-wood.webp` 资源提示。
- 本轮是浏览器手机视口模拟，没有中端安卓真机的帧率、流量和刘海安全区实测。
