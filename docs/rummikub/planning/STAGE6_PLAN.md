# 阶段 6：XP 5–6 人

用户在阶段 5 完成后说“继续吧”，按总指令的下一阶段实施 XP；不涉及 Twist、推送、部署。沿用此前通过的原版产品、交互、视觉规划和服务器权威架构。

来源：[官方 2600-English.pdf 第 1 页](https://rummikub.com/wp-content/uploads/2019/12/2600-English.pdf)、[官网 XP 页面](https://rummikub.com/product/rummikub-xp/)，2026-10-25 复核。XP 使用四颜色 × 13 数字 × 3 副本 + 4 Joker = 160，5/6 人每人 14 张。其他已裁定规则沿用原版实现。

需求与边界：默认 classic / 2 人 / 106 张；仅房主可切换 xp，xp 只允许 5/6 人，切换重置准备，不能挤出已入座玩家。经典旧存档默认恢复为 classic；模式、牌池、私有草稿、seq、累计分在重连、进程重启和下一局保持。

设计：大厅增加“玩法”选择和当前模式说明；人数随模式切换。首页仍使用 Classic 官方包装，不将其冒充 XP 包装。对局明确显示 XP 标记，手机能访问六个座位，复用既有牌架、组合、Joker 美术、ActionDock。不开新样式体系。

验收：先引擎及房间负例；经典默认不变；160 张唯一身份，第三副本和 J3/J4 可用，经典守恒拒绝 XP 牌；5/6 人私密视图、回合事务与计分；5/6 人各 200 个种子模拟；真实六浏览器大厅、开局、私有操作、重连、重启、整局和下一局；390×844 / 844×390 / 桌面截图；经典联机与 UI 脚本回归；全仓测试、类型检查、构建和受影响专项。写阶段 6 交接、仅本地提交后停止。
