# 拉密第 2 阶段 PRD

来源：PRESSURE_TEST.md 的 Proceed、总指令 §1–2、RULE_MATRIX.md、CHECK_REQUIRED.md。
问题/用户：朋友私人游玩的规则计算须独立于浏览器和网络，避免规则误判与泄漏。
目标：纯引擎完整单局和多局，全部规则行为可回归；非目标：服务器/UI/XP/Twist/全局最优 AI。
用户旅程：抽先手→发牌→当前玩家编辑私有草稿→提交或摸牌→轮转→终局摊牌计分→下一局。

| ID | 必须需求 | 验收 |
|---|---|---|
| REQ-001 | 106 唯一牌、2–4 人、14 张、公开抽先手 | 固定种子可复现；平手重抽；抽牌归池 |
| REQ-002 | 全部合法 Joker 解释，顺子高分优先 | 端点/缺口/两 Joker/缺色/无环绕反例 |
| REQ-003 | 破冰 ≥30、只用本人牌、整回合不能动旧桌面 | 29 拒绝、30 接受；Joker 按解释值 |
| REQ-004 | 私有 MOVE/SPLIT/MERGE/UNDO/REDO/RESET | 正式桌面不变，撤回和重做守恒，桌面牌不可回手 |
| REQ-005 | COMMIT 原子校验，中文拒因 | 非法恢复快照罚 min(3,pool)，回合结束，原状态不变 |
| REQ-006 | 摸牌结束、计时设置及服务端超时入口 | DRAW 1；提前超时拒绝；到期回滚罚 3；不限不超时 |
| REQ-007 | Joker 释放与本回合复用 | 官方四例；释放 Joker 不能回手或只移位置冒充新组 |
| REQ-008 | 隐藏投影与权限、幂等 | 他人仅手牌数，不含牌池内容或草稿/历史/快照；重复 seq 无动作 |
| REQ-009 | 正常/堵局计分、多局累计与胜局 | 零和；堵局点差；重开保留积分，胜局优先排名 |
| REQ-010 | 600 局固定种子完整模拟 | 2/3/4 人各 200 局到终局，保存种子、步数与结果 |

非功能：每次 reduce 开启不变量检查时所有 106 ID 恰出现一次；不可变输入，无系统时钟或随机隐式调用。随机由创建时服务器传种子；deadline 使用服务器传入 now。无日志手牌或行为分析上报。
可见文案：具体组号/牌名/差分，不用通用“错误”；界面视觉规格留总指令阶段 4。
风险和问题：9 项边界继续开放且使用已登记默认，不将模拟 PASS 当成完整可行性证明。
发布：只做本地分支不部署。Ready for `$groovy-alignment`: Yes。
