# Pressure Test

## Idea / Situation
用户要求在现有桌游合集供朋友私人联机游玩官方原版拉密；当前没有拉密引擎，线下实体/其他网站为现有替代方案。现在先完成可测试的纯引擎，联网与 UI 分阶段另做；不假设有商业收益或已验证用户规模。

## Tension
前三风险：Joker 重组误判、隐藏信息泄漏、超时默认与官方冲突。依赖已核官方 PDF、RULE_MATRIX、CHECK_REQUIRED。复杂重组、空池、并列与重复提交是维护成本；模拟 AI 不是完整重组求解器。

## Alternatives
| 方案 | 收益 | 代价 | 决策 |
|---|---|---|---|
| 不开发，线下或现有网站 | 零维护 | 无法使用当前合集/本地房间 | 不选；用户已明确要求合集 |
| 只做独立纯引擎 | 规则可测，风险隔离 | 暂不可网页游玩 | 本阶段采用 |
| 同时实现联网和 UI | 快速可见 | 跨层问题难定位、违背阶段停止点 | 后续阶段 |

## Recommendation
Decision: Proceed。信心中等：用户需求和来源明确，边界依照已登记默认值，不冒称官方规定。PRD 必需输入已具备：总指令、24 条矩阵、9 项边界与阶段停止点。压力测试仅是基于当前证据的代理评估，不伪称用户访谈或市场验证。
Ready for `$prd-writer`: Yes。
