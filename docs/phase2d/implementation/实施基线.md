## 设计基线

视觉主张：潮冷雾林、旧铁与骨白，旧黄铜用于当前动作；暗背景中主体轮廓可辨。地图为视觉主体，避免面板堆叠。既有原创PNG优先复用为WebP，并补齐独特物品与模块图，中文由代码渲染。

内容：正式联机建房只选人数，进房自选阵营，系统随机地图和角色选项；手机沿用JoinRoom/LobbyRoom/DraftRoom，测试专用preset走选座；热座保留地图与角色配置；对局顶部轮次/阶段/进度，最新事件单行；棋盘/路线/角色；底部本阶段动作；头像入口打开角色资料，日志按需展开。桌面保留工作区与侧栏。

交互：选牌抬起和顺序编号；移动镜头跟随；对象结果反馈与骰子同次呈现。减少动画按用户设置/系统偏好。图像加载失败立即保留SVG；在途禁用发送，服务端拒绝显示中文原因，断线显示重连条。

状态：准备翻道具、秘密计划、移动、交互、技能时机、骰子选择、搬运、等待/重连、结算。每种都由真实state与getControls驱动；表单选项来自commandFields，不自己推导合法性。复杂目标采用大按钮分页选项，不下拉。

可访问性：大热区、中文label、可见焦点、动作与颜色双重编码；安全区；无双击误触，不禁用整站用户缩放。镜头移动不改变规则结果。
