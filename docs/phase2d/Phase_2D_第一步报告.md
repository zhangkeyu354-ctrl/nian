## 发现与样稿验证

现有技能使用实测2次；统一先点房间的放木板路径实测4次，均超过目标；该路径不代表所有操作方式的理论最少点击。补测并计入反馈确认后，本次翻道具、攻击、躲柜、抓取、治疗合计3次，搬运1步合计4次（含骰子与后续反馈两次确认），详见审计表。计划、技能、结束、搬运需要页面滚动；有44px及20.9px热区。HTTP冷进入初始房间约57.73MB，中局69.95–84.61MB，不含WebSocket。正式版当前仍不满足8MB。

独立样稿在官方iPhone 13与Pixel 7设备描述下使用Chromium触屏验证：逃生者计划2次、杀手3次、移动1次、修理交互2次，页面无滚动/下拉，受检可点热区均≥48px，未连接真实房间。6张样稿截图通过统一截图检查器；隐藏棋盘的负例被拒绝。[样稿验收记录](样稿验收.json)。已人工检查三场景及Pixel截图，并运行develop-web-game标准浏览器客户端检查读屏状态与截图。

样稿使用真实合法回放的显示模型与轻量SVG占位，不执行对局、不伪造规则结果。正式房间插画优化、所有情境接入、提示音/震动、常亮、PWA，以及两局正式手机触控整局验收均留到用户确认后的第二步。
