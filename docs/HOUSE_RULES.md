## U-ITEM-TIMING：物品在数字版里的使用时机（2026-10-19，Claude 实现的默认做法，待用户确认）

卡文时机原文见 `ITEM_DATA.json`。实体桌游里"任何时候"可以随时出声打断；数字版需要明确的暂停点。默认做法：

| 卡文时机 | 物品 | 数字版做法 |
|---|---|---|
| 在你的回合中 | 工具箱 | 自己回合（移动前或交互阶段）随时按，不占用交互机会 |
| 在任意逃生者的回合中 | 宽敞工具箱、急救箱、地图、彩虹地图 | 任意逃生者回合中随时按，**不用等提示**；不是自己回合的持有者在"我的物品"里按 |
| 在杀手的回合中 | 手电筒 | ①杀手在你的空间宣告交互时，系统暂停询问；②杀手回合中、他还没交互前也可以主动按。只阻止交互，**不阻止杀手力量**（B01 p14：力量是"代替交互"使用的） |
| 任何时候 | 鞭炮（阻止进入） | 杀手将要进入你的空间时系统暂停询问。被阻止 = 移动失败，按 B01 p18 FAQ 也失去本次交互。搬运途中不能被鞭炮阻止（搬运整段一次结算） |
| 任何时候 | 鞭炮（移除墙壁） | **Q10 未裁定，暂不可用**（明确提示"待裁定"） |
| 任何时候 | 三种钥匙（重掷） | 任何逃生者掷骰出现失败时，系统暂停询问；每颗骰子最多重掷一次（B01 p16）；被替换掉的失败不再给杀手血点（B01 p18） |
| 任何时候 | 三种钥匙（血点） | 随时可按 |

- **不泄露手牌**：系统暂停询问时，询问的是"该位置上所有手里有物品的逃生者"，不是只问真正有鞭炮/手电筒的人。手里有没有物品本来就是公开的（实体游戏里看得到桌上有一张牌），具体是哪张不公开。
- **使用后公开**（U-ITEM）：打出后立即弃掉，所有人都看到是哪张、用在了什么上。
- **医生「压迫性气场」**：在物品打出之后、生效之前触发；危险骰失败则物品已弃掉、不产生效果。
- **躲在储物柜里可以用物品**（B01 p12 只禁止柜内使用技能）；**挂在钩子上不能用**（被献祭视为不在版图上）。
