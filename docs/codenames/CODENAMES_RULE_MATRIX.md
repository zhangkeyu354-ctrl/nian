# 《行动代号》规则对照表

来源等级（沿用 AGENTS.md）：**B** = CGE 官方规则书（2015 英文版）/ 官方 FAQ；**OBS** = 2026-10-21 在 codenames.game 实测；**HR** = 用户在开发指令 V2.0 中指定的线上规则（House Rule）；**IMPL** = 本项目为实现做的选择（不改变原版规则）。

| 编号 | 规则 | 原版（规则书） | 官方网站实测 | 本项目 | 依据 |
|---|---|---|---|---|---|
| R01 | 人数 | 至少 4 人，两队人数相近；2–3 人有变体 | CLASSIC 标 4+ | 标准模式 4 人起（每队 1 队长 + ≥1 猜词者），上限 12 人；2–3 人变体不做 | B p.2 / HR 1.1 |
| R02 | 队长 | 每队选 1 名卧底（spymaster） | 玩家自己点「卧底」面板 | 两种模式：随机队长 / 自选队长；整局固定 | B p.2 / HR 1.2 |
| R03 | 棋盘 | 25 张词 5×5 | 同 | 同，服务器从词库随机抽 25 个不重复词 | B p.2 |
| R04 | 身份分配 | 先手 9、后手 8、中立 7、刺客 1 | 实测 9 vs 8 | 同，服务器随机 | B p.3 |
| R05 | 先手 | 钥匙卡上的灯决定（随机） | 随机（本次蓝先） | 服务器随机红/蓝先手，先手拿 9 张 | B p.3 |
| R06 | 线索格式 | 一个词 + 一个数字 | 文字框 + 0–9/∞ | 文字框 + 0–9/∞ | B p.4 |
| R07 | 线索不能是桌面上可见的词 | 规定（含变形、复合词的一部分） | **不检查**（TOKYO 被接受） | 服务器拦截：线索等于或包含任何**未揭晓**的桌面词 → 拒绝提交并提示，不算违规 | B p.4/6 / IMPL |
| R08 | 无效线索惩罚 | 回合结束 + 对方卧底可盖掉自己一个词 | 无 | 不实现（R07 已在提交前拦截明显违规；其余由朋友口头裁定） | B p.5 / 见 GAPS Q1 |
| R09 | 至少猜一次 | 必须 | 未测 | 普通情况下必须翻 1 张后才能「结束猜词」；超时例外 | B p.4 / HR 2.4 |
| R10 | 猜词上限 | 数字 N → 最多 N+1 次 | 实测 1 → 2 次后自动换边 | N≥1 → N+1；达到后自动结束本回合 | B p.5 / OBS |
| R11 | 数字 0 | 不限次数（至少 1 次） | 有 0 按钮 | 不限次数，受 120 秒约束 | B p.7 / HR 2.4 |
| R12 | 无限 ∞ | 不限次数 | 有 ∞ 按钮 | 不限次数，受 120 秒约束 | B p.7 / HR 2.4 |
| R13 | 猜中本队 | 继续 | 同 | 同 | B p.4 |
| R14 | 猜中中立 | 回合结束 | 未测 | 同 | B p.4 |
| R15 | 猜中对方 | 回合结束，对方得该牌 | 未测 | 同 | B p.4 |
| R16 | 猜中刺客 | 猜的一方立即输 | 实测：对方队伍获胜 | 同 | B p.4 / OBS |
| R17 | 获胜 | 本队所有牌被翻开即胜，**即使在对方回合翻开** | — | 每次翻牌后检查双方剩余数，归零方获胜 | B p.5 |
| R18 | 卧底不能猜 | 卧底只盖牌 | 卧底点牌无反应 | 服务器拒绝队长翻牌/标记 | B / OBS |
| R19 | 提示计时 | 沙漏可选、无自动结束 | 软计时，超时后对方可手动结束 | **60 秒**硬计时；超时自动结束本队回合 | HR 2.2 |
| R20 | 猜词计时 | 同上 | 同上 | **120 秒**硬计时；超时自动结束（不要求已猜 1 张） | HR 2.3 |
| R21 | 加时 | 无 | 无 | 每队每局 1 次 +30 秒，只能本队猜词阶段、计时未归零时使用；不加猜测次数；下一局重置 | HR 2.5 |
| R22 | 翻牌确认 | 特工指着牌，卧底盖牌 | 任一特工「标记→点手形确认」 | 任一猜词者可标记；只有本队**操作员**能确认翻牌；本队其他猜词者可一键接任操作员 | HR 2.3 / IMPL |
| R23 | 计时权威 | — | 服务器 | 服务器保存截止时刻；客户端只显示 | HR 2.6 |
| R24 | 下一局 | — | 保留队伍和设置，卧底重选 | 保留队伍和设置；自选模式队长清空重选，随机模式开局重新抽 | OBS / HR 1.2 |
| R25 | 结束后公开 | — | 全员可见 25 张颜色 | 同 | OBS |
