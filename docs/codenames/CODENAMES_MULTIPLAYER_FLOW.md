## 2. 本项目联机设计

复用现有 Socket.IO 服务器（与黎明杀机、魔法运动员同一进程），事件名加 `cn:` 前缀，房间存档独立目录 `data/cn-rooms/`。

### 事件

| 事件 | 方向 | 说明 |
|---|---|---|
| `cn:create` | 客户端→服务器 | 建房，返回 4 位房间号 |
| `cn:join` | → | 带 token 重连；返回快照 |
| `cn:claim` | → | 新玩家输入昵称加入（成为观众），返回 token |
| `cn:lobby` | → | 准备阶段操作：选队、当队长、改模式、随机分队、开始 |
| `cn:command` | → | 游戏内操作：出线索、标记、确认翻开、结束猜词、加时、接任操作员 |
| `cn:update` | 服务器→每个连接 | 按身份过滤后的快照 |

### 服务器权威

- 所有随机（抽词、身份分配、先手、随机队长）只在服务器。
- 计时：状态中保存 `deadline`（毫秒时间戳）。服务器为每个房间设一个定时器，到点发 `TIMEOUT` 命令；任何命令都会先检查时间，过期操作被拒绝（`TIME_UP`）。
- 每条命令带 `version`；版本不对拒绝（`STALE`），防重复提交和多人同时点击。
- 快照里带 `serverNow`，客户端计算本地时差后显示倒计时，刷新/重连后自动对齐。

### 隐私

`viewForCN(state, playerId)`：
- 队长：看到全部 25 张的身份。
- 其他人（队员、观众）：只看到已揭晓的身份；未揭晓牌的 `role` 字段不存在（不是隐藏，是根本不发）。
- 结束后：全部公开。
- 随机种子、词库顺序不发给任何客户端。

### 断线重连

- token 存浏览器 `localStorage`（键名 `cn-seat-房间号`），刷新或断网重连自动回座。
- 掉线不影响计时；队长掉线超时也会自动换边。
