# 《行动代号》UI/UX 分析与本项目设计

依据：`CODENAMES_OFFICIAL_RESEARCH.md` 的实测观察。

## 1. 官网做得好的（借鉴交互思路，不复制美术）

| 设计 | 为什么好 | 我们怎么用 |
|---|---|---|
| 整页背景随当前队伍变色 | 不用读字就知道轮到谁 | 顶部状态条和页面底色随红/蓝切换 |
| 「标记 → 确认」两步翻牌 | 语音讨论时随便点，不会误翻 | 点牌 = 标记（显示标记人数）；操作员再点「确认翻开」大按钮 |
| 新线索大字横幅 | 所有人第一时间看到 | 线索提交后中央弹出 1.5 秒大字「线索 · 数字」 |
| 游戏记录按线索分组 | 方便回顾「还漏了哪个词」 | 可折叠的「记录」抽屉，每条线索下列出翻开的词和颜色 |
| 揭晓后整张牌换成纯色+图案 | 揭晓与未揭晓一眼区分 | 揭晓牌用队伍纯色底 + 小图标，词仍可读（变淡） |
| 结束后全员看到全部颜色 | 赛后复盘的乐趣 | 同 |
| 断线头像标记 | 知道谁掉了 | 玩家名单显示「离线」 |

## 2. 官网的不足（我们要改进）

| 问题 | 改进 |
|---|---|
| 手机竖屏上牌面字很小（英文窄体约 9–10 px） | 中文词 2–4 字，牌面字号 ≥ 17 px；网格占满宽度 |
| 确认翻牌的小手按钮只有约 24 px | 底部固定一个全宽「确认翻开：XX」大按钮 |
| 不检查无效线索 | 提交前服务器拦截桌面词 |
| 软计时需要对方手动切 | 硬计时自动切换（用户要求） |
| 计时只是数字 | 进度条 + 最后 10 秒变红 |
| 队长和队员的界面差异只靠颜色条 | 队长顶部固定标签「你是队长：只有你看得到颜色」 |

## 3. 页面清单（对应指令 Phase 3）

1. 游戏大厅：首页加第三个盒子「行动代号」。
2. 创建房间：大厅点「开房间」→ 自动建房 → 进入房间页。
3. 加入房间：房间号 / 邀请链接 / 二维码，输入昵称加入。
4. 红蓝分队：两列（红队、蓝队）+「观众」；每人点自己要去的队；房主可「随机分队」「把 X 移到…」。
5. 队长分配：房主切换「随机队长 / 自选队长」；自选模式下每队面板有「我来当队长」。
6. 棋盘：5×5，手机竖屏占满宽度。
7. 队长秘密视角：未揭晓牌显示颜色边框/底纹 + 刺客标记；顶部提示条。
8. 队长提示输入：底部固定面板：文字框 + 数字一排（0–9、∞）+「发出线索」；60 秒倒计时条。
9. 队员讨论与猜词：点牌标记；操作员底部「确认翻开」；「结束猜词」；「+30 秒」。
10. 结算：大字「红队获胜 / 蓝队踩中刺客」+ 全部颜色公开 + 「再来一局」（房主）。
11. 再来一局：回到房间页，保留队伍和设置。

## 4. 主界面信息层级（手机竖屏，自上而下）

1. 状态条（当前队伍颜色）：「红队 · 队长出线索」/「蓝队 · 猜词」+ 倒计时大数字 + 进度条。
2. 比分：红 剩 X · 蓝 剩 Y；两队「+30 秒」是否已用（⏱ 可用 / 已用）。
3. 当前线索：「水果 · 2」+「还能翻 3 次」（0/∞ 显示「不限次数」）。
4. 5×5 棋盘。
5. 底部操作区：按身份和阶段显示（队长输入线索 / 操作员确认翻开、结束猜词、加时 / 其他人显示「等待 XX」）。
6. 折叠抽屉：玩家名单、线索记录、规则速查。

## 5. 防误触

- 标记与翻开分离；翻开按钮写出要翻的词。
- 「结束猜词」在 0 次猜测时置灰，并说明「至少先翻一张」。
- 加时按钮二次确认：「本局只能用一次，确定加 30 秒？」。
- 所有按钮提交后在服务器回应前禁用（防连点）。
