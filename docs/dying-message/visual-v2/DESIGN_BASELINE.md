# 《请留遗言》照片还原基线（取代原创V2）
用户明确拒绝原创立绘及华丽AI风格，要求尽量还原提供的图片。停止所有图像生成，不再使用已生成的酒店/黄铜圆桌/原创人物。

15角色均从用户五张照片直接校正提取，保持原本的人物、压暗眼睛的画法、黑紫底、粉色英文标题和左右竖排信息。只做四角校正与裁切，没有模型重画或换脸。牌背也提取照片中的原版粉色牌背。圆桌使用照片中实际木桌纹理与克制的深色桌沿，不使用宫殿、黄铜、卷草装饰。

页面配色直接取原卡：近黑/暗紫为背景、鲜粉作主要操作强调、白色文本，无罪青蓝和有罪红仅在可公开身份时显示。桌面主圆桌加侧边身份/操作；手机圆桌在上，身份与行动在下。保留1–10座与全部动作。

证据卡继续使用用户确认的153张原创无字插画，不修改；原版身份卡含原印刷文字，与证据卡无字要求分开。HTML补充可读的中文能力说明。

原版照片和派生卡面只作本地使用，遵守仓库原版素材不提交公开Git的规定；本地素材路径与来源在reference/dying-message/记录。代码与验证可提交，原卡面不随公开仓库上传。本次不部署。
