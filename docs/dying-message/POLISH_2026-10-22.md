# 请留遗言精修（2026-10-22，Claude）

用户要求消除贴图感、提升界面和操作反馈。没有改任何规则、协议或服务器。

## 改了什么
- **材质与光源**：`dm/polish.css`（只加不删的覆盖层，作用于 `.dm-polish`）。背景吊灯光 + 颗粒 + 暗角；圆桌改为木框绒面、中心烛光；座位立体投影；侧栏毛玻璃；按钮统一材质、弹簧按压、扫光；不可点按钮改为深色可读而不是半透明。夜晚阶段桌面光变冷。
- **座位状态**：可选目标呼吸光；选中浮起 + 旋转准星（行凶为红色）；发言者金色光环脉冲；死亡褪色 + 红叉印；自己金边；杀手可见同伴红边。
- **底部行动栏**（`ActionDock`）：所有主按钮移到屏幕底部，显示「已选：X号」「已选 2/2 张」「剩余 4:32」等；不是自己操作时显示等待原因。按钮 testid 不变。
- **阶段横幅**（`useStageFeedback`）：夜幕降临 / 轮到你行凶 / 你遇害了 / 天亮了·X号遇害 / 第一次投票 / 最后的辩解 / 轮到你发言等，1.9 秒自动消失，不挡点击。
- **投票揭晓**（`VoteReveal`）：每次投票后弹出票数条与「过半」章，4.5 秒自动关；同时到来的横幅排在之后。终局不弹，直接结算。
- **计时圆环**：中央倒计时外圈，30 秒变橙、10 秒变红并滴答。
- **卡牌**：发牌入场、按压、选中序号徽章；公开遗言终局盖真/假章（绿/红）；身份牌翻牌入场。
- **结算**：赢家彩带、"你赢了"盖章动画，次要按钮改为描边样式。
- **音效与震动**：复用 `drawing/feel.ts`（WebAudio 合成，顶栏喇叭按钮开关，与绘画派对共用设置）。
- **修复**：空座位被误判为"正在发言"（undefined===undefined），大厅所有空位发金光。
