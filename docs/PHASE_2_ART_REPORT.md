# Phase 2补充：道具状态、交互反馈与原创素材

2026-10-19。保持Phase 2热座范围，不进入联机或卡牌效果阶段。先完成SVG/功能检查，再调用内置image_gen生成PNG；全部工作完成后报告并停止。

## 已实现

- 同一套引擎只读投影与组件覆盖41种状态：四类背面、发电机、出口大门、钩子、图腾、箱子、储物柜、木板、乌鸦、墙壁、杀手标记及角色状态。目标黄、无惧红、逃生蓝、援助绿，文字与纹样同时区分。
- 发电机完成后移到进度轨；移除道具只留空槽，路线木板、捕兽夹、鬼灵陷阱、神经紊乱和恶灵各有专属图标。墙壁保留锯齿提示，破坏状态不影响引擎通行计算。
- 角色有原创剪影与中文名、受伤环、挂钩与搬运状态。公共棋盘不绘制躲藏者；储物柜只显示“被占用”，无角色姓名、ID、头像或工具提示；相关公共日志和检定结果匿名化。本人热座私有操作面板与公共棋盘分开。
- 翻牌使用实际类别的背面翻到正面；骰子滚动并区分三种结果；修机进度条增长、角色受伤闪红、挂钩专属落下/锁链、移除/惊飞与胜利结算反馈。动画仅展示真实事件与状态差，不结算规则或改随机数。
- 设置可关闭全部动画，也可单独关闭PNG；设置保存在本机并尊重系统减少动态效果。手机以短transform/opacity动画为主，没有持续粒子或视频背景。

## 原创素材

`docs/ART_STYLE_GUIDE.md`统一风格、尺寸、透明背景与隐私规范。32份原创SVG占位先完成；随后生成32份原创PNG，包括8类道具、4类背面、墙/标记、原创灯笼、13名基础角色和匿名剪影。没有使用官方图标、角色图或Logo作为生成参考，原来的计数划痕式品牌装饰已替换。

实际工具输出均为1254×1254透明RGBA，保留原生文件；界面按统一规格缩放。`assets/manifest.json`登记来源、文件、对应状态、SVG回退、实际尺寸、提示词及SHA-256；浏览器副本同步。PNG加载失败或主动关闭时使用SVG；已测试故意中断PNG请求的回退，也修正了缓存图片加载与回退标记的时序问题。

全部中英文设计提示与实际英文生图提示见`docs/ART_PROMPTS.md`。透明通道和文件检查见`phase2-art/PNG_AUDIT.json`。32份素材均为本项目原创AI生成，本次角色采用全新匿名剪影设计。
