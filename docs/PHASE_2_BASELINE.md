# Phase 2 已授权范围与设计基线

本阶段是既定桌游项目的已授权界面实现，用户已给出范围和验收标准，不新增游戏规则。沿用Phase 1规则、U02裁定和待核边界。

视觉：深色桌面承载暖灰房间，彩色路线为主要视觉锚点，金色只用于当前操作；不使用原版图片充当棋盘。内容顺序为顶部局势与进度、主棋盘、下方当前角色与牌/技能、侧边事件日志。操作反馈使用路线点亮、骰面进入、交接遮挡淡入；尊重减少动画设置。

交互：引擎查询提供当前操作者、合法移动/交互和选择；前端只处理展示、表单、地图缩放与交接。秘密计划仅当前玩家可见，切换玩家时清空界面并显示遮挡，刷新后也先遮挡。此阶段是同设备可信热座，不宣称开发者工具层面的隔离；联机服务端私密状态留Phase 3。

手机：竖屏地图可拖动/双指缩放并有缩放/复位按钮；常规按钮至少44px。地图房间/道具选择后在下方显示同等的大按钮操作，避免小目标成为唯一入口。中文技能全文、费用、血点/健康、物品始终可查。

验收：引擎单元测试与资料审计、构建/类型检查、两张地图由浏览器真实点击从准备至胜负、截图视觉复核；额外检查遮挡无秘密DOM、合法路线、骰子记录、CHECK_REQUIRED提示及手机拖动缩放。既有Phase 1回放不直接灌入界面状态。

技术参考：[React官方入门](https://react.dev/learn)、[Vite官方指南](https://vite.dev/guide/)、[Tailwind官方Vite安装说明](https://tailwindcss.com/docs/installation/using-vite)。沿用SVG可交互节点，因此完整验收采用DOM点击脚本；已运行develop-web-game自带客户端做启动/遮挡烟雾检查，其鼠标动作依赖canvas，不能替代本项目的SVG/表单验收。
