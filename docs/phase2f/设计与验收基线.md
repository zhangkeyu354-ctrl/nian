# Phase 2F 设计与验收基线

原始任务：在 ui-2f 分支执行 PHASE_2F_黎明杀机界面与反馈升级.md，验收后提交并推送该分支，停止；禁止部署和推送 main。

这是已批准的 Phase 2D/2F 连续改进，产品范围以本阶段指令为准，复用 docs/phase2d 的操作审计和用户确认方案。仅改变公开状态的呈现与触摸反馈；合法性、伤害、技能费用与时机继续由引擎决定。

## 表现约定

- 深青黑迷雾底色、磨损黄铜与米白字、危险朱红；原创透明剪影头像，13 人各有轮廓特征。36px 对照表检查辨识度。
- 动画约500ms，沿现有棋盘路线几何移动；三岔路线经过同一个交汇点。道具脉冲、进度填充、事件播报只订阅新公开事件。
- 本人受伤/杀手接近显示非阻挡边缘提示；其他玩家不能借动画得到柜中角色身份或秘密移动牌。
- 技能显示名称、费用和引擎给出的短效果；不可用时灰色并解释原因，不创建新的合法性分支。
- 48px触摸目标；缩放后小房间在屏幕坐标扩展到48px，避免巨大透明路径覆盖邻居。
- 音效由 WebAudio 合成，设置和系统减少动态效果优先；非交互浮层 pointer-events:none。

## 验收方式

先用独立引擎重放验证事件数与胜负，再用真实点击/触摸驱动正式界面。截图使用 screenshot-check.ts 的解码和像素检查，全图另校验房间/路线数量。开发专用反馈页面只检验动画中间帧与服务器拒绝表现，不能替代联机整局验收。开发服务器测试期间冻结生产源码，发现问题后结束本轮再修改并重跑。

原图、提示词和来源见 PORTRAITS.json；所有图为内置生图工具全新生成，无官方参考图输入。
