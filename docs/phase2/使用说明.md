# 中文热座界面

在项目目录使用Node.js 24：

```powershell
npm ci --ignore-scripts
npm run dev
```

在同一台电脑浏览器打开 http://127.0.0.1:5173/ 。也可运行`powershell -ExecutionPolicy Bypass -File scripts/start-hotseat.ps1`，缺依赖时先安装再打开浏览器。5173已使用时复用原界面或停止原进程。无需上传任何原版图片。

1. 选地图、四名不同逃生者与一名杀手。3–4名玩家时按界面自动分配兼控；角色始终为四名逃生者加一名杀手。种子固定时可重现随机结果。
2. 交接时先让下一位玩家接过设备，按“我是该角色的玩家，查看棋盘”。准备阶段依次点击一个未翻开的道具；也可用下方大按钮。
3. 秘密计划时点击移动牌，棋盘预览第一张牌从当前位置出发的合法路线；杀手按顺序选两张。确认后交接给下一位玩家。第二张牌在其行动时按实际位置重新高亮。
4. 行动时点亮的路线由引擎给出。点击目的房间执行移动；有多条路线时在下方选具体路线。点击道具/角色所在房间可选择合法交互；结束行动同样经引擎处理。
5. 技能响应时查看全文和费用，可使用技能或点“不使用技能，继续”。有目标的技能会打开参数表单；目标、时机和费用由引擎验证。克劳黛特血点交换须先向目标玩家确认自愿，医生力量须询问受影响玩家后填写其决定。
6. 每次出生骰或检定结果都会单独显示，按“已查看，继续”。多骰保留在随后选择。事件日志和全部掷骰记录可回查。
7. 搬运时依次选择房间/路线，选择挣脱骰数量再确认。路线能否通过由引擎检查，途中不翻道具。

地图可拖动、双指缩放，也有放大/缩小/复位按钮。小屏全图是总览，放大后点选；下方提供大按钮作为同等操作入口。桌面按F切换全屏，Esc退出。

交接遮挡会卸载秘密牌和棋盘DOM；这是同一台设备的可信热座，完整状态仍在该浏览器内存中，开发者工具层面的秘密隔离留Phase 3。刷新页面重新开局，本阶段没有存档/联机。

Phase 4的物品效果和五项延后技能尝试使用时显示“该功能尚未实现”，不扣费、不改对局。切勿据此认为已实现全部卡牌效果。当前能力范围见`../phase1/ABILITY_SUPPORT.json`。

自动验收：先`npm run dev`，另开终端运行`npm run verify:hotseat`、`npm run verify:mobile`、`npm run verify:actions`。首次安装测试浏览器运行`npx playwright install chromium`。脚本只点击实际界面，不向浏览器注入棋盘状态或命令；预定命令在Node端用于选择按钮和独立核对。图片与结果输出在被Git忽略的output/playwright/phase2/。
