# M4人物主动能力进度（2026-10-22）

M4进行中，本次完成牧师和说书人的引擎及联机协议，尚未通过M4全部特殊交互验收。沿用已批准的范围与设计基线，采用tdd-builder：先观察11项牧师、13项说书人测试因缺少命令失败，再实现并回归。没有开始部署。

## 1. 已完成

- 牧师：自己回合以公开弃牌堆0～2张非黑牌替代抽牌，每局两次，行动后结束回合；禁止出牌后使用、黑卡、重复牌、伪造牌和越权使用。
- 说书人：自己回合选择带能力的抽牌行动，私人查看整副牌堆，可重排阴谋和夜晚，每局一次、60秒。服务端只接受原有全部实例的排列，不能添加、遗漏或复制牌；排序不触发黑卡，实际抽到时按正常事件结算。
- 排序只给本人（包括同一身份的多台设备），其他玩家无牌堆内容、无中间排序更新、无公开修订号变化。截止时间与已接受顺序保存至原房间存档；刷新、服务器重启可恢复。重复排序/完成请求不会重复抽牌。
- 沿用当前房间服务、卡牌实例、行动队列、黑卡中断与续抽，不新增独立网站。

## 2. 原版依据与线上方案

原版能力依据：[官方人物图06](https://www.facadegames.com/images/products/salem-1692-06.jpg)，用户人物图06用于中文核对，人物矩阵H07/H13；[官方标准规则](https://www.facadegames.com/files/rulebooks/salem-1692-rulebook-english.pdf)P2的30秒沙漏及P14说书人可移动全部牌、仍可抽牌、夜晚正常重建。人物图上的两次沙漏对应60秒。牧师以本回合抽牌替代取牌，不采用旧版“额外行动”的文本。

线上方案单独记录：`TITUBA_START`明确代表玩家选择“抽牌并使用能力”，因此完成排序后执行本次抽2张并结束回合；不暗中允许查看后改成出牌。客户端可多次保存准确排列并提前确认。到服务器截止时间，使用最近一次已保存顺序，自动结束查看并执行已经选择的抽牌行动。超时策略是数字交互约定，**不是声称官方规则书写有自动抽牌**。断网不会重置计时，也不替玩家选择新的排序。

裁缝复制这两种有限次数能力的次数归属仍为X10待核，明确拒绝相应复制分支，未假称官方已明确。
