版本：salem1692-standard-15th-printing-4to12-2026-10-22。研究日期：2026-10-22。
主依据：[官方标准版PDF](https://www.facadegames.com/files/rulebooks/salem-1692-rulebook-english.pdf)，第15次印刷。已下载、全文提取，并实际查看全部24张逐页渲染图；不能把PDF文字提取器漏掉的图片内文字当作不存在。
本文件是规则事实的中文整理与可追溯规范，不是整本规则书的逐字翻译。P为PDF页序，从封面算第1页；1～22页的印刷页码与PDF页序一致，23～24按PDF页序定位。

## 1. 权威与范围
1. 本项目4～12人标准玩法以该PDF快照为首要依据；具体条款优先于同书概述。官方同版卡面补足未重印的能力；出现与PDF不符的宣传图则保留差异、按PDF执行。
2. 明确作者答复补充未说明项，记录是否早于当前印次；不能让旧答复覆盖当前PDF，例如旧“牌堆抽空才洗”答复不覆盖P8/P14。
3. 用户旧中文版、第三方教学、社区牌表降为历史/待核证据，不能自动补成标准规则。
4. 仅支持4～12人；P16～17的2～3人变体已研究但不启用；P15进阶选项默认关闭；豪华版机制不进入标准牌池。
5. “已核实”表示该字段有相符依据；“待澄清”留有明确问题，不等于删掉能力或授权自定义。

## 3. 规则矩阵
| ID | 触发/阶段 | 标准行为与必要顺序 | 依据 |
| --- | --- | --- | --- |
| R01 | 开局 | 依实际人数取P3身份池，洗混分配，秘密查看后背面排放；人物公开，每人1张，≤7人可2选1 | P3 |
| R02 | 准备行动牌 | 先移出夜晚和黑猫；其余洗混发每人3张，发到阴谋则洗回并换牌；余堆分半，夜晚混入下半堆 | P4 |
| R03 | 配件 | Frame只保留本局人物对应项，用于无主持人秘密选目标；主持人不算参与玩家；线上服务器替代主持是改编方式 | P3～4 |
| R04 | 初始黎明 | 仅开局一次；女巫互认并给任何玩家黑猫，可给自己；黑猫持有者先行动，顺时针 | P4、P10、P5 |
| R05 | 普通白天回合 | 抽2张结束，或至少出1张且可连出多张；不能先正常出牌再改选正常抽2。人物能力按各自时点 | P5、P14 |
| R06 | 一般出牌 | 不给自己打牌或锤子，不通过抢劫/嫁祸直接让自己获益；明确自用例外按原文；出牌落定不能撤回 | P9 |
| R07 | 卡区 | 绿卡使用后弃；拘留留至跳过回合才弃；蓝卡持续到出局/被移除/移动；红卡累积计点 | P5、P14 |
| R08 | 审判 | 通常7点，不是7张；达门槛者选择目标一张未公开身份揭示；弃该次全部红卡，超额不结转；多次审判逐次结算 | P5、P13 |
| R09 | 黑卡抽取 | 抽到立即执行，占本次抽牌额度；能力抽到同样立即中断，完成后回原进度；剩1张夜晚可夜后补原本第2张 | P6、P12 |
| R10 | 阴谋步骤 | 先由抽到者揭黑猫持有者一张身份，无猫略过；各人同时取左邻一张隐藏身份；查看后洗混自己的隐藏身份；公开身份不传 | P6、P9 |
| R11 | 永久阵营 | 任何时刻取得女巫身份便永久入女巫；失去该牌仍在女巫阵营并参加夜间女巫行动 | P3、P6、P11 |
| R12 | 警长 | 只在当前持有未揭示警长牌时行动；失牌即失职；揭示警长牌后该身份职能本局停用，可仍存活 | P3、P7、P12 |
| R13 | 夜间 | 女巫共同秘密选一个袭击目标（可自己）→警长秘密保护别人→全体自白窗口→公开目标和豁免检查 | P7～8、P11 |
| R14 | 自白 | 在目标公开前，自选自己一张身份公开，换本夜被Frame袭击豁免；窗口一柱沙漏。它不自动免除揭示女巫/耗尽身份等其他死因 | P8、P11、P5/P14 |
| R15 | 夜袭豁免 | 原目标受到锤子保护、已自白或有避难则不因本次袭击出局；女巫警长也可故意救错人；不可自保 | P7～8、P12 |
| R16 | 夜末牌堆 | 夜晚先取出，原牌堆余牌与弃牌一起洗混，再把夜晚混入新堆下半部；每夜均执行，哪怕阴谋尚未抽到 | P8、P11～12 |
| R17 | 说书人 | 可移动阴谋和夜晚到任意堆内位置；能力后仍可抽牌。提前抽到夜晚仍按R16重建，不等待余牌用尽 | P14 |
| R18 | 基本出局 | 身份全揭、单张女巫揭示或夜袭成功会出局；但多女巫牌例外R19优先；死亡展示余下身份，手牌和蓝卡弃掉，人物接管见冲突审计 | P5、P14 |
| R19 | 多女巫牌例外 | 持多张女巫牌，揭其中一张时告知另有女巫牌并继续，不按P5一般句立即出局；“后来失去最后一张隐藏女巫牌”的复合情形仍待澄清 | P14 |
| R20 | 平民胜利 | 本局最后一张女巫身份公开即胜，不要求把所有曾成为女巫者逐个杀死 | P6 |
| R21 | 女巫胜利 | 所有平民被消灭，或最后一名平民感染；后一情形该最后感染者个人输，其他女巫按阵营胜 | P6 |
| R22 | 情侣 | 同一人不可获第二张；一方出局牵连另一方，夜间保护/自白不免该牵连；女仆本身免不利效果但其死可牵连对方 | P13及牌面插图 |
| R23 | 情侣终局例外 | 若牵连会造成两阵营同时输，只消灭原目标，不消灭被配对者；不沿用旧版“先后相差一瞬”的裁法 | P13 |
| R24 | 信徒 | 持有者审判门槛翻倍，可受红卡；失去信徒且已有≥7点即揭一张，移除信徒者选择；非通常人物门槛组合见X07 | P13卡面、P13～14 |
| R25 | 门槛组合 | 普通7、法官6、大力士8、法官对大力士7；有信徒对应14、12、16、14 | P14及官方人物卡 |
| R26 | 仅剩两人 | 抢劫和嫁祸不可出；不自动引入旧中文“清空所有蓝牌/蓝牌补抽”。本PDF蓝牌持续规则仍有效 | P5、P13 |
| R27 | 信息/退出 | 死亡必须展示余身份，但默认不要求说曾属女巫；三个英文“last words”后静默；公开阵营是P15可选简化，不默认启用 | P5、P9、P15 |
| R28 | 思考计时 | 拖延时翻沙漏；到时结束回合，尚未出牌者抽2结束，已出牌者不额外抽 | P9 |

人物/行动卡完整数据分别见[人物矩阵](WITCH_TOWN_CHARACTER_MATRIX.md)、[卡牌目录](WITCH_TOWN_CARD_CATALOG.md)。复合结算尚缺的执行细节见[冲突审计](WITCH_TOWN_RULE_CONFLICTS.md)，不是以规则开发者自由裁定。

## 4. 已证的局部顺序
P6：黑猫揭示先于阴谋传牌；P12：黑卡立即中断能力抽牌；人物卡Ann：奖励抽牌在原审判揭示前；P13：非终局情侣原目标及配对者的出局不能被普通夜袭保护覆盖，双输例外必须先检查；P8：自白窗口先于目标公开，夜后重建先于恢复剩余抽牌。
其余并发触发不能从上述局部规则推出任意全局排序；未定项保留，不给“人物总优先”或“死亡总优先”的无证通则。

## 6. 豪华版隔离
交叉阅读[豪华版PDF](https://www.facadegames.com/files/rulebooks/salem-1692-deluxe-rulebook-english.pdf)：P3身份表增特殊牌，P8～9先令/标记，P10特殊身份，P17自定义标记。它有五种特殊身份（Charlatan、Gravedigger、Inquisitor、Magistrate、Pickpocket）、先令、Bless/标记系统及复活等机制，均排除。官网另有豪华宣传图把某身份标成Arsonist，也不能混入标准版。
标准版仍有一枚警长锤子；排除豪华标记并不排除标准锤子。标准版黑猫/避难/情侣/信徒为行动牌，不替换为木标记。
