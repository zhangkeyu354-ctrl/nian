# M2白天执行基准

沿用已授权PRD/对齐/设计，本阶段实际实现：黎明共同选黑猫接通白天；普通抽2或出至少1张后结束；红/绿/蓝牌合法目标与生命周期；普通审判及已确认人物触发。服务端实际调用同一纯函数reducer，无测试专用跳过黎明接口。

黎明线上协调：所有存活女巫分别秘密提交目标，全部一致才落定，允许修改自己的目标；无多数决、无随机代选，普通玩家视图不含候选、参与者名单或数量。这是线上交互约定，原版共同选择目标及自选允许不变。

内部任务队列保存奖励抽牌、原审判、回合结束等续程。每抽一张就检查黑卡；黑卡占本次额度，进入black-event状态，保留事件牌和剩余任务。M3才能结算，不提供客户端“跳过黑卡”命令。

审判由最终出牌者选择目标隐藏牌序号，不给其他玩家隐藏实例ID或牌面。达到门槛只审判一次，揭牌后弃全部红牌，超额不结转。Abigail/Ann有可放弃的能力窗口；Rebecca非致死揭示有逐次抽牌窗口。Ann抽黑卡时原审判仍在续程中。

明确CHECK_REQUIRED边界：X01部长证据与Alibi移除计点，X02致死揭示奖励/中断原目标死亡，X03裁缝失部长复制后过阈值执行者，X06女仆免疫蓝牌及嫁祸重复情侣，X07信徒移除的特殊门槛，X09农民分牌争议，X10复制有限能力使用次数。不静默略过相应能力；受影响命令事务回滚，其他路径继续。

人物复制方向：加入顺序为顺时针，面向桌心时右邻为前一个存活席位。使用可选能力必须显式选择，不自动替玩家决定。说书人/牧师主动能力留M4，拒绝未知命令；普通抽牌仍合法。

死亡/胜负提供审判所需的基础结算：多女巫牌例外、全身份展示、蓝牌/手牌清理、情侣死亡与双方同输例外、全部女巫牌公开或无存活非女巫者。农民和复杂复制触发仍按上述待核边界拒绝。阴谋、夜晚及自白不在本阶段伪造完成。

本阶段无正式UI、不部署。存档兼容M1时补入队列/回合字段，私人视图白名单扩展；每条游戏操作仍按凭证、版本、requestId、原子保存执行。M2自动化分别覆盖4～12，随机测试标为白天步骤，不冒充完整游戏。
