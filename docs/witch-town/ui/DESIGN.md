# 女巫镇 M5 · 关卡1设计基准

2026-10-22。依据用户M5指令、已通过的产品需求/对齐记录。范围：可交互的假数据视觉稿，未接Socket.IO，不代表完整产品。关卡1截图交付后停止，等待用户与Claude审阅，不进入关卡2。

## 先看精修，为什么首版总像贴图

本次阅读：`docs/dying-message/POLISH_2026-10-22.md`、`dm/polish.css`、`dm/Polish.tsx`；`docs/drawing-party/POLISH_2026-10-22.md`、`drawing/studio.css`、`drawing/feel.ts`、`drawing/Covers.tsx`；`ma/MagicalAthlete.tsx`的Overlay/RollingDie/Fold、`ma/ma.css`的骰子动画/自己的光环、`ma/playback.ts`的事件队列。

| 反复返工的原因 | 代码与记录中的具体证据 | 本版从第一天执行 |
| --- | --- | --- |
| 素材没有共同空间 | 遗言补吊灯、木框绒面、座位投影；画室重写纸/木/黄铜/玻璃与聚光 | 先画房间、窗、桌和烛灯；物件共用光源、接触影、环境影与表面高光 |
| 全站按钮样式侵入 | 绘画派对全站button排除st/lb；遗言反复覆盖disabled | 全站基础button增加wt排除；wt四态自管，不可用深底浅字、opacity=1 |
| 数据变化没有可感知顺序 | 遗言阶段横幅、投票揭晓；运动员大骰子落定后才位移、技能横幅 | 永久任务提示+短暂非阻塞横幅；确认、翻牌、烟雾、数值反馈分开；后续真实事件按序播放 |
| 主操作跟着内容移动 | 遗言ActionDock修复手机主按钮可达性 | 所有主操作在安全区内固定底栏，提示和按钮分两行，长文不挤按钮 |
| 只检查一种尺寸 | 画室计时折行、画架压字、结算挤按钮；运动员Fold减少手机负担 | 四尺寸逐场景截图；不缩小文字来凑布局；详情/日志折叠、内部滚动 |
| 美术是最终覆盖层 | 两次POLISH都是已上线功能后的补层，CSS出现大量补丁 | 本次先冻结材质/信息/互动基准，视觉审核通过才接协议 |

结论：不是“图片不够精美”，而是缺少统一的空间、组件边界和状态呈现。增加装饰不能替代这三个基础。

## 视觉与信息主张

1692年清教徒小镇的月夜：冷月光穿过左上窗框，桌心烛灯照亮旧木、墨绿绒面、羊皮纸与蜡封。原创SVG小镇、人物小像和卡面符号，卡牌外壳由CSS绘制，不复用官方插画。

第一层信息是“现在是谁、做什么”；第二层是圆桌局势；第三层是自己的牌。详细卡文、角色能力、公开蓝牌和记录放可关闭的详情层。桌面不是拉宽手机：圆桌居中且保持比例，右侧独立私人区域，左侧保留小镇环境空间。

## 色板、光源与材质参数

所有颜色只在`.wt-world`变量区声明；CSS组件与SVG引用变量。正文≥13px。标题：`"Noto Serif SC", "Songti SC", "SimSun", Georgia, serif`；正文：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；不请求在线字体，离线可用。

光源：月光屏幕左上(14%,8%)，投影向右下；烛灯桌面(50%,50%)，边缘高光和微弱暖色反射。`--wt-shadow-contact: 2px 3px 3px #00000080`；`--wt-shadow-raised: 5px 12px 22px #00000080`；`--wt-shadow-float: 8px 24px 48px #000000a6`；`--wt-highlight: inset 1px 1px 0 #ffffff29`。坐席依据相对烛灯位置计算向外的次级影，月光主影始终右下。玻璃层使用12–18px blur，高光在上左，不能成为发白色块。

层级：背景(0，窗/小镇/颗粒/暗角)→木桌和绒面(1，厚边+环境影)→座位与纸牌(2，接触影+边框)→任务与私人面板(3)→详情与底栏(4)。纹理/灯光不接受点击。所有装饰不遮文字。

日间仍是月夜主题，但暖光面积大；夜晚暖光收缩、桌面变暗、窗格月影增强。光照层opacity/background-color过渡1.5秒，不瞬间换皮。减少动画设置下跳过。

## 响应布局与可读性

- 手机竖屏：顶栏→永久任务提示→圆桌→自己的审判牌与横向扇形手牌→固定行动栏。页面不横滚；只有手牌/详情内部可滚。
- 375×667：缩小留白、头像及装饰，文字仍13px；长事件使用替换私人区域的面板，不额外堆高。
- 844×390：左侧圆桌、右侧私人/事件面板；顶栏与底栏占独立行；不靠整体scale压小文字。
- 1440×900：圆桌最大720px宽、保持椭圆比例，右侧320px私人区；环境小镇占侧边，内容不无限拉宽。
- 座位：以自己为0号相对位置，沿实际容器椭圆等弧长取点（720步采样），`x=50+rx*cos(theta)`，`y=50+ry*sin(theta)`。10人以上增加`-.05*sin(4*theta)`的统一对角间距修正；rx为39%，紧凑桌41%；ry上限39%，按座位高度和选中浮起的安全间距自动收缩。没有按人数手写坐标。4～12人均测试四种尺寸，自己始终最下中。12人核心只显示头像/编号/昵称/角色/指控进度，剩余信息点开详情；字号不能用scale压缩。
- 主控≥44px；紧凑座位整块可点。图标按钮必须aria-label；选中状态兼有描边/准星，不仅颜色；focus-visible清楚；Esc关闭详情。
- 四边使用env(safe-area-inset-*)。行动提示单独占行、按钮nowrap，不让标题挤按钮。

事件区独立预算：手机一般238px，小屏190px，不能沿用手牌托盘高度而裁掉标题/牌面。说书人和终局在手机使用完整工作区；短横屏排序/结果为左右两栏，长名单在面板内纵向滚动。桌面保留圆桌与侧栏。手机有单独构图的原创窗框/小镇SVG，避免把宽幅背景居中裁切后只剩纯色。背景月亮避开任务文字。
