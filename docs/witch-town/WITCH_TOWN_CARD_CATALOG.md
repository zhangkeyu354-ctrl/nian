# Salem 1692 标准版：15类行动牌目录
基线：官方标准版第15次印刷，2026-10-22。本文件替代旧CN优先目录。
主来源：[标准PDF](https://www.facadegames.com/files/rulebooks/salem-1692-rulebook-english.pdf)，页码以PDF页序计；官方卡图可补充未印卡文，但若不符PDF则PDF优先。

共通：普通行动牌在自己出牌回合使用；不以自己为目标；有明确人物例外则适用例外。黑卡在任何抽取时立即执行。绿通常即弃，拘留延迟；蓝持续；红累计点数。下面“已核实/补证/待澄清”针对效果，张数另见[数量表](WITCH_TOWN_CARD_COUNTS.md)，不得自动借用旧版配比。

**目录边界**：标准版59张行动含黑猫；Frame配套15张不计行动牌；人物15张与身份39张也分别建类。豪华的Bless、Shilling、木标记、特殊身份均不加入上述15类。
**持续牌与清理**：P5正面定义蓝牌持续，当前PDF未规定仅剩两人自动弃蓝/补抽；不从旧版移植。拘留绿牌在P14有明确延迟弃例外。
**审判结算**：使用当前点数/门槛，达到门槛才揭一张，再弃本次所有红牌；不把单张7点/3点拆成可携带的余额。
**死亡接管**：农民/裁缝的具体战利品数量有PDF与官网卡图不一致，不能把同一批牌既发手牌又入弃牌；未明确前保留X09。
所有未定项均有[冲突审计](WITCH_TOWN_RULE_CONFLICTS.md)和[未来测试](WITCH_TOWN_AUTOMATED_TEST_CHECKLIST.md)，不靠删除卡牌解决。
