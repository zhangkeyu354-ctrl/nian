## 4. M3执行审计补充（2026-10-22）

- X09单人农民：解除过宽的整项阻塞。官方人物图06明确其他人死亡时收其全部手牌与蓝牌入手；PDF P12的“三张”语句是农民和裁缝共同分配的条件句，不能据此给单人添加三张上限。本轮实施单一继承者全收；共同分配与复制源本人死亡仍CHECK_REQUIRED，X09未整体关闭。
- X04：普通同时传牌、警长转移、历史女巫不回退、最后单一平民感染的个人败北已执行；猫主翻出最后女巫导致终局时直接结束。猫主非终局死亡、公开女巫失最后隐藏女巫、多个最后平民同时感染仍保留。180局仿真里该类阻塞38局（37猫主非终局死亡、1公开女巫失最后隐藏女巫）。
- X02：普通家庭主妇奖励抽黑卡并恢复外层传染已实测；少女奖励的原审判也保留。若原审判选择者/目标已在中断中死亡，明确CHECK_REQUIRED，避免等死人选牌；不猜测继任选择者。致死首次揭示的主妇奖励仍保留。
- X05：按标准正文保护别人，主动弃权仍未核，不使用2～3人例外；身份揭示后本局警长职能停止，已测试。
- X08：奇数半副约定保留；正常夜末重建与补抽已运行；没有其他牌可重建的极端状态不凭空补牌。
- 在线信息边界：未完成的传牌选择/女巫投票不产生公开修订或更新；保护锤在自白阶段公开，袭击目标只在夜末公开。服务器遇会依赖隐藏信息的待核分支，会保存具体内部审计码，但客户端只见通用待核状态并锁定该事件，避免反复试选把错误变成探牌工具。
