# 《犯罪现场》美术补充需求（Claude → Codex，2026-11-21）

用户反馈：卡牌美术可以，但身份牌、选地点、事件、入口、夜晚、房间号等处太朴素，和游戏氛围不搭。本次**只做图片资源**，不改任何代码（界面接入由 Claude 负责），不改规则、数据和测试。

## 统一风格（以用户认可的 284 张证物卡为准）

- 和证物卡同一套画法：复古印刷/水粉质感的写实静物，单一主体，柔和顶光与接触阴影，纸张纹理与轻微颗粒。
- 底色沿用卡牌体系：线索类暖红、手段类墨绿、场景/档案类深棕与旧纸色；夜晚类用冷蓝绿。
- **不画人物、不画脸、不画血腥**；图片里**不出现任何文字、数字、Logo**（文字由界面叠加）。
- 不要海报感、不要强烈霓虹和发光边、不要塑料 3D 渲染。宁可克制，像实体桌游配件的印刷图。
- 横幅类图片：主体放在**右侧三分之一**，左侧留出干净的暗部给文字。

当前用矢量轮廓的 6 张：`means-005 手枪`、`means-019 火药`、`means-053 砍刀`、`means-055 炸药`、`means-060 狙击`、`means-086 电棍`。按其余手段牌同一风格重做，输出 `cards/<id>-512.webp` 和 `cards/<id>-1024.webp`，并把 id 加进 `apps/web/src/cs/card-art.json`。
