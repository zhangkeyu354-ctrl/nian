# 《犯罪现场》质感基线

2026-11-21。视觉论点：像把原版证物卡、场景板和弹壳标记摆在深色绒布桌面上；层次来自实体厚度和局部光照，画面保持干净。

## 大厅现状

来源：`apps/web/src/game-hall.css` 的 `.hall2`、`.cart-art`、`.hall-sheet`、`.hall-primary`。大厅以暖顶光和四周暗角形成桌面；卡带使用上缘高光、内边线、底部深色厚度和接触阴影；主按钮使用三段金色渐变、内高光、底部 4px 侧边；按下下沉 2px 并同步缩短阴影。入场曲线为 `cubic-bezier(.2,.9,.3,1.1)`，面板约 250ms，按压约 120–180ms。字体以清晰的系统中文为正文，标题用较重字重；本游戏的牌名和章节标题继续用现有 `ZCOOL XiaoWei`。

## 使用边界

- 纹理只作为低对比材质，不盖住文字。原版证物卡仍以单件物品为主，不添加叙事海报。
- 材质变量和动作类统一放在 `apps/web/src/cs/crime-scene-materials.css`；各屏只规定位置与尺寸。
- 案件板要在 390×844 手机上以 2×3 同屏呈现。概览文字可紧凑，专家落标提供更大的选项操作区。
- 所有动态 150–400ms；按压可 120ms。减少动态效果时关闭非必要动画和变形。
- 逐屏验收保存到被忽略的 `output/cs-ui/polish/`，和大厅截图并排核对。
