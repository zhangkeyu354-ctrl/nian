## 复现当前轻量验收

1. `npm test -- --maxWorkers=1`、`npm run typecheck`、`npm run build`。
2. 设置`MA_PLAYERS=2`、`MA_SECOND_WIND=1`、`MA_SPEED=fast`、`MA_TEST_SEED=2601030`，运行`npx tsx scripts/verify-ma-browsers.ts`。游戏服务器独立临时数据目录，不访问线上房间。
3. 视频工具使用隔离依赖：`npm install --prefix work/ma-motion-tools --no-save typescript@5.9.3 ffmpeg-static`。设置`MA_MOTION_OUT=output/ma-motion-lite`、`MA_MOTION_BUILD_ONLY=1`，运行`npx tsx scripts/measure-ma-motion.ts`，**仅构建真实UI夹具，不做三轮性能采样**；再运行`npx tsx scripts/verify-ma-motion-lite.ts`，生成MP4及六骰面检查。
