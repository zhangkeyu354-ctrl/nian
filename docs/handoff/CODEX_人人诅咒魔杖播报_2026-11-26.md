# 人人诅咒魔杖播报交接

用户反馈：扭扭赛道的「人人诅咒魔杖」每回合末跳过谁，只能到页面下方比赛记录中查，当前画面看不清。

本分支 `codex/ma-curse-wand-broadcast` 在引擎现有跳位结算上增加结构化 `curse_wand` 回放事件，携带掷骰玩家、点数、按原顺序被跳过的角色（含已淘汰或已冲线状态）及实际下一位行动者。原有跳位和日志规则不变。客户端每次结算时播放骰子并显示中央播报卡片；支持点屏幕跳过、动画速度和减少动态效果设置。小屏卡片内的名单可以滚动。

测试：`twisty-curse-wands.test.ts` 检查结构化数据与已淘汰顺位，`ma-twist-card.test.tsx` 检查玩家可见文案。`scripts/verify-ma-curse-wand-broadcast.ts` 用真实浏览器验证手机、桌面和减少动态效果模式，并截图到 `output/ma-curse-wand-broadcast/`。第一次手机截图发现卡片右侧溢出，修正 `box-sizing` 后三种模式均通过。

定向测试 15/15，`npm run typecheck`、`npm run build`、`npm run verify:replays` 通过；全站测试 2027 通过、1 跳过；`npm run verify:mobile-interfaces` 64 场景通过。`npm run verify:ma-browsers` 通过：4 人、4 场、1327 步、8 次事件卡确认。额外修复上一轮留下的二代赛道预览脚本中已删除的 `monsterRacers` 字段与旧断言，`npx tsx scripts/verify-ma-second-wind-tracks.ts` 的 10 屏幕/5 宽度及传送验证通过。此分支未推 main、未上线。
