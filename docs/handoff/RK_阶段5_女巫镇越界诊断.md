## 原因与最小修复方案

`apps/web/src/wt/WitchTown.tsx` 的手牌区固定使用 `wt-hand-fan`，旋转角为：

```ts
(i - (hand.length - 1) / 2) * 2.5
```

19 张时两端为 ±22.5°。扇形布局为每张牌预留的宽度随牌数减少，但旋转角持续增加，导致两端牌面超出屏幕，并被个人面板裁切。

候选方案仅将该计算改为：

```ts
(i - (hand.length - 1) / 2) * Math.min(2.5, 16 / Math.max(1, hand.length - 1))
```

少量牌保持原有间隔，较多牌将总展开角约束在 16°，不改变牌区结构、引擎或协议。需要用户允许修改女巫镇视觉行为后，才能写入产品代码，再完成 360/390 手机、横屏、大量手牌、完整对局与类型检查等验证。
