基于最新 main `ec71245` 创建 `codex/xb-layout-fix`；执行文件位于 `docs/instructions/XB_LAYOUT_FIX_2026-10-25.md`。

## 改动

- 新增 `.xb-world` 作用域的手机竖屏样式：100dvh、固定顶栏和操作栏、舞台内部滚动；座位条单行横滑，64px 座位、40px 头像、12px 姓名和分数，总高 76px。
- 原美术按人数放大座位的规则限制在平板竖屏，手机不再使用两排及 260/296px 上限布局；横屏和平板的原区域尺寸保持一致。
- 发言计时使用原数据绘制头像外圈；自动横滑显示自己或新发言人。状态保留头像角标和光环，离线灰色角标。
- 闭眼、身份、真相/回顾与终局隐藏座位条。终局前三名（包括并列）在舞台完整显示，其余排名紧凑排列；“每轮回顾”作为舞台文字入口，“再来一局”保留在底部。
- 操作栏主按钮 52px，提示最多一行，次操作压缩，保留错误/网络反馈和 iPhone 安全区。没有修改玩法、计分、题库、联机协议或其他游戏样式。
