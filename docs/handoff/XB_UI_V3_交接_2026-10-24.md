## 本轮实现

- `FirstGame.tsx`：首次成功进房三页滑动教学，跳过、完成和菜单重看；三种身份分别记忆首次提示。教学弹窗支持焦点约束与 Escape。每轮同步9秒闭眼，所有玩家相同点屏动作；仅老实人获得真实解释，其他人打开同尺寸思考卡。
- `xb-aids.ts`：辅助数据与引擎 State 分开存档，包括阅读／揭晓服务器时间、每人发言累计时长、想想标签、目标私有点名、娱乐投票。旧存档字段可缺省，旧局直接展示已完成揭晓；新局生成独立 gameId，防止跨局复用动画标记。
- `VoiceAid.tsx`：想想点头像点名，只有被点的人收到提示及震动；公开发言人状态正常同步。房主开局前可选30／60秒或不限；计时累计每个人本轮发言，耗尽只提示，不操作外部麦克风、不强制切阶段。禁言者不能被点名，已存在的点名提示随禁言或发言人切换立即撤销。
- 小抄为可疑／像真的／？及清除，不加文字输入。讨论时服务端只给想想发送；已揭晓轮次的标签才进入公开快照，观察者也收不到未揭晓标签。
- `TruthRecap.tsx`：已揭晓题目、答案及来源横滑回看；皇冠每人每轮一票，服务端拒绝重复／越阶段投票，终局统计“最离谱瞎掰”称号。投票前后整个引擎 State 字节串一致。
- `.xb-world` 内统一4／8／12／16／24间距、圆角／阴影令牌和14／17／22／28四档文字。10人长名字用单行省略和完整标题；360宽无横向滚动。发言条的文字层级和两排座位高度已单独验证；横屏座位区允许纵向滚动。
- 总音量滑杆使用XB独立的归一化音频通道，默认70%，可以调到0。复用绘画音频合成底层，其他游戏未选择新通道时的音色、包络、默认主音量和震动参数保留。
- 刷新按服务器时刻恢复剩余阅读／揭晓时间；session标记避免重放。切后台清掉飞行、金币、贴纸等临时效果并完成揭晓，回来直接显示结果；后台不播放音效或震动。

## 复验与边界

- 本地预览：`http://127.0.0.1:3359/?game=xb`。本轮服务数据 `output/xb-ui-v3/` 与生产隔离。
- 专项：`npx tsx scripts/verify-xb-ui-v3.ts`；需先构建，并在3359运行本地服务。脚本自建3361极限夹具服务并关闭，不覆盖现有房间。
- 整局：设置 `XB_TEST_URL=http://127.0.0.1:3359`、`XB_ARTIFACT_DIR=output/xb-ui-v3/full-games` 后运行 `npm run verify:xb-browsers`。
- 音频：开发服务5173运行后执行 `npx tsx scripts/verify-xb-audio.ts`。测量是实际合成音效的离线电平，不代表实体手机扬声器的主观响度。
- 后台验收通过浏览器 visibilitychange 模拟调用生产监听器，并检查实际WebAudio节点启动次数；未进行实体手机操作系统级切后台验收。振动仍取决于浏览器支持和用户设备设置。
- 浏览器禁止存储时采用内存回退避免崩溃；这种环境无法承诺跨刷新记忆教学或身份令牌。
- 构建保留既有大包提示，以及 `table-wood.webp` 的运行时路径提示；本轮未更改该资源，已有游戏回归检查覆盖实际页面。
