# 魔法运动员房间：角色范围预设

## 用户要求

四场地图已经能逐场自选，移除地图区的「仅一代／仅二代／一二代混合／随机赛程重抽」快捷按钮；把三档预设放到角色选择，替换「开启新角色／只用新角色」两层勾选。保留轮流选秀和随机发选手两种分配方式。

## 实现

- `apps/web/src/ma/MagicalAthlete.tsx`：三档角色按钮通过现有 `SET_SECOND_WIND` 动作控制原版、仅二代、混合角色池，所有玩家同步看到当前选择，仅房主可改。地图区保留四场逐场选图。
- `apps/web/src/ma/ma.css`：三档按钮在手机宽度下可换行，选中态明显，选秀说明留足间距。
- `scripts/verify-ma-browsers.ts`：检查地图快捷按钮已移除，逐场选图可用，角色三档切换与客人同步、房主权限。
- `apps/web/src/update-notices.ts`：在玩家公告顶部加入简短说明；旧公告作为历史记录保留。

服务器协议、旧房间存档和已经开始的比赛均未改动。`npm test -- --maxWorkers=2 --reporter=dot`：181 文件通过、1 跳过，2018 项通过、1 跳过；`npm run typecheck` 与 `npm run build` 通过。浏览器四人完整四场通过（1346 步），手机和电脑房间截图在 `output/ma-role-pools-browser/`，已目视核对按钮和选中态。此分支未推送 `main`，尚未上线。
