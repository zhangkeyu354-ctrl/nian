# 脑洞量表答题卡改版：Claude 接手收尾（2026-11-01）

Codex 在额度用完前已完成答题卡改版的引擎、协议、服务器和大部分 UI（未提交）。Claude 接手后复验并修了以下问题：

## 修复
1. **队长排序快速点两张卡交换时偶尔不生效**：之前要等服务器回包才换位置，连续操作会被网络锁吞掉。改成本地立即换位，后台按顺序排队发送最新顺序；服务器拒绝时退回服务器顺序。
2. **倒计时滴答**：改为同一阶段内每秒只在秒数下降时响一声，时钟校准回跳不重复响，并加 600ms 实时保护。
3. **测试脚本**：`verify-nd-ui.ts` 的滴答计数在 Chromium 下一次发声会触发两次 start 钩子，改为 50ms 内去重。
4. **排序列表**：竖屏改单列，回答 18px 最多 2 行，名字一行省略；宽屏（≥700px）两列。
5. **旁观者**：非队长看排序时不再显示拖动把手，卡片不再变灰。
6. **翻卡背面**：回答文字放在数字下方、加粗 15px 作为主角，名字缩小一行省略，不再挤压重叠；卡高 156px。
7. **写卡**：输入框右侧留出空位，不被「我的数字」徽章压住文字。
