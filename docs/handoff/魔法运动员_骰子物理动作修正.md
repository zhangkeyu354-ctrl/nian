# 魔法运动员：骰子僵硬反馈修正

基线：main dd028e0。分支：codex/ma-dice-physics。2026-10-30。

## 问题与修正

用户指出上一版骰子动作僵硬。原实现先绕固定轴播放曲线，再把当前姿态插值到结果面，两个阶段的水平位置、角速度没有连续衔接；预设弹跳和压扁也不符合硬骰子的接触行为。

改为仅用于显示的桌面刚体轨迹：固定240Hz积分，重力、圆角接触冲量、摩擦及角动量共同决定下落、碰撞、翻面和停稳。每次掷骰提前算好轨迹，播放帧只采样位置/四元数，不触发React逐帧更新，不引入物理库或服务端变更。750ms掷出加620ms收尾窗口不增加，服务器在750ms切换揭晓状态时不再重启动画。全程保持骰子刚性。

显示结果的方法：利用立方体对称性对整条轨迹做一致的面映射，从第一帧到最后一帧显示同一套面；不在尾帧强转到点数。结果仍由服务器提供。为了让碰撞落点留在手机画布内，最多尝试6条物理轨迹，不适合的取景使用已验证的轨迹；不夹住位置、不设隐形墙。减弱动态效果、三档速度、CSS回退、GPU释放沿用原有机制。

只改骰子与验收工具；删除已不使用的预设骰子曲线。其他动作、游戏规则、人物技能均未改。大厅公告增加“骰子翻滚动作重做”。
