## 3. 界面需要知道的接口变化（Phase 2D 第二步要接上）

**规则仍然全部由引擎给出，界面不要自己算。** 以下都已在 `getControls()` 或 `itemActions()` 里列成完整命令。

### 物品
- 命令 `USE_ITEM {actorId, itemId, ...}`。**不要自己拼参数**，用 `itemActions(view, actorId)`：返回该角色此刻所有合法的物品按钮（完整命令 + 中文文字）。
- `getControls()` 已经在三种情况自动带上物品按钮：自己回合的移动阶段、交互阶段、物品响应窗口。
- **必须新增**：不是自己回合也能用物品（"任意逃生者回合中""任何时候"）。手机操作坞需要一个常驻"我的物品"入口：对自己座位的每个角色调用 `itemActions(view, id)`，非空就可点。联机时 `App.tsx` 对"不是我行动"的玩家返回空操作，所以这里要单独调用。服务器不限制轮次，直接发送即可。
- 旧界面只发 `{type:"USE_ITEM", actorId}` 的"使用物品"按钮会被拒（缺参数），请换掉。
- 物品打出即公开（`ITEM_USED` 事件带物品 id），建议做一个"物品牌翻开"的反馈。

### 新的选择类型（`state.choice.kind`，`getControls` 都已列出按钮）
| kind | 谁 | 做什么 |
|---|---|---|
| `MAP_REVEAL` | 用地图的人 | 依次点至多 3 个背面道具，`SELECT {}` = 翻完 |
| `PHANTASM_TARGET` | 妖巫 | 原目标躲进柜子后，在同一空间重选攻击/搬运对象 |
| `CARRY_REROUTE` | 杀手 | 搬运被鞭炮拦下后，一步一步改道（剩余步数在 `choice.budget`），`SELECT {}` = 停下 |
| `REPLAN` | 被幽灵「穷追不舍」选中的逃生者 | 从手牌重放一张 |

### 窗口
- `window.itemActors`：这次暂停在问哪些持有物品的人。只依据"有没有物品"，不泄露是哪张。
- **用完技能/物品后窗口可能直接转到下一位**，不要假设还是同一个人，以 `window.actors[window.index]` 为准。
- 钥匙：每次有逃生者掷骰，持有物品的逃生者都会被问一次（用户要求可以重掷成功的骰子）。手机上这一步要做成一键"继续"。
