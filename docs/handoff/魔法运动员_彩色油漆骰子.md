# 魔法运动员：彩色油漆骰子

2026-10-30，基于main 30a4b31，分支codex/ma-dice-paint。

用户明确给出六色参考图：彩色油漆块、圆润亮面、黑色细描边和奶油白凹点。此前“短线笔触”的理解不准确，本轮改为图中的彩色油漆方向。

## 实现

- 保留六种主色及第7、8席粉/青；每色配置三种协调的浅色油漆。
- 在骰体的局部三维坐标中绘制不规则色块，色块连续跨过圆角并随实体翻滚，不使用逐面贴图，不产生接缝或追随屏幕的滑动。
- 点数凹坑、黑色轮廓为独立几何/材质，油漆只作用于骰体，不覆盖点数。
- 增加柔和清漆反光；移除之前的短线涂鸦。备用CSS骰子也使用相同配色的色块。
- 调色数据为轻量模块，Three.js仍维持原来的延迟加载；不新增图片、贴图请求或GPU纹理资源。
- 骰子大小、刚体轨迹、服务端点数、技能判定、字幕出现时间和播放窗口均未改。

## 验证

- 实际WebGL：三档速度各两轮六面=36次正确落定；减少动态效果6面及对决2面正确，共44个结果。未出现着色器编译错误。
- 390×844、390×664、1366×768：单颗与对决不重叠、不溢出；保留单颗手机218.4px/电脑224px的画布尺寸。
- 96个文件、1360项全量测试、类型检查、构建通过；两人开启新角色726步完成四场，3次数据页，5名新角色参赛，零页面错误。3份重放逐事件一致、64个手机界面通过。资源检查24次创建/18次释放，保留当前6个上下文；CSS备用六个点数正确，减少动态效果停止RAF。
