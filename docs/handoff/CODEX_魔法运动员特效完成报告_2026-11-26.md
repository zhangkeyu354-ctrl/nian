# 魔法运动员比赛特效：完成报告（2026-11-26）

工作分支：`codex/ma-second-wind-tracks`。未合并或推送 `main`，未上线。

## 实现

- 新增独立 `RaceFx.tsx`，只引用 `assets/cc0/vfx/` 的序列帧和 `assets/cc0/particles/` 的白色粒子；未下载素材，也未改黎明杀机的 `BoardFx.tsx`。
- 螺旋世界的合法配对管道：起点 `portal`、棋子抵达后终点 `teleport`，光晕取管道格颜色。Twist 抽卡用 `reveal` 与 `magic_02`。巨口怪物和大嘴狼人淘汰用 `slash`，其他淘汰用 `break`。
- 角色能力用小号 `power`，正向拿筹码用 `coins`，绊倒用 `dust`，决斗用 `slash`。冲线第一、第二名用 `complete` 与金/银色星光；领奖台第三名用较小的铜色装饰（不发铜牌积分）。附加决赛开始用一次轻量 `complete`。
- 特效由 `playback.ts` 的日志队列触发。移动相关效果在棋子到位后出现；反向赛道使用 `Track` 已有的物理格坐标。每次最多显示 4 个，同种同人同格的连锁效果合并；快档省略高频小效果，所有时长跟随动画速度。系统减少动态效果时不创建效果，CSS 也隐藏效果层。效果层不接收鼠标事件。
- 只改魔法运动员前端；未改规则引擎、联机协议或 `privacy.ts`。
