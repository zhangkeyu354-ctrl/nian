# 扭扭赛道抽卡提示修复

## 用户反馈与复现

玩家反馈扭扭赛道像没有抽卡，缺少像选手技能那样的弹窗。引擎专项复现表明首名选手跨过第 13→14 格时，`race.twist.drawn` 确实记录卡牌且效果会执行；但抽卡日志没有结构化动画事件。比赛动画只从文字推测“待抽卡”，而移动动画记录先于抽卡日志，导致提示时序不可靠。许多事件没有移动特效，手机上的比赛记录默认折叠，因此玩家看不到明确反馈。

## 修复

- 抽卡日志附带 `twist_card` 动画事件，包含触发者与卡号。连续抽卡逐张记录，动画按原日志顺序播放。
- 中央事件卡弹窗显示卡号、中文名称、简短效果说明和触发者；先显示抽卡，再播放后续技能、传送、淘汰等效果。保留棋盘上的 CC0 翻卡粒子。
- 扭扭赛道和螺旋世界开场提示分别解释抽卡边界与管道落点；比赛棋盘上保留两条赛道的简短规则提示，扭扭赛道抽卡后显示已抽事件名称。温和、狂野赛道原有说明保留。
- 弹窗时长按玩家动画速度缩放；“减少动态效果”关闭入场动画，但保留可跳过的静态说明。

## 验证与发布状态

专项测试覆盖首次抽卡、连续抽卡顺序、13 张事件的说明、四种赛道开场说明。真实浏览器固定卡 02 的手机、电脑和减少动态效果截图在 `output/ma-twist-overlay/`，检查脚本 `scripts/verify-ma-twist-overlay.ts` 通过。全站测试 182 文件通过、1 跳过，2024 项通过、1 跳过；类型检查、构建通过。四人新赛道浏览器完整四场通过（2593 步，3 次赛后统计画面）。未推送 `main`，未上线。
