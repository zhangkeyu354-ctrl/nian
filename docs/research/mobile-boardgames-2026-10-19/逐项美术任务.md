# 逐项美术任务与验收卡

这是待执行的创意简报，不是本次已经生成的素材。已有文件见素材覆盖清单；以下特征为原创视觉方向建议，不新增官方设定、人物能力或数值。继续遵守原创剪影肖像边界，优先改善轮廓、服饰和边缘光；若要升级成清晰面部半身立绘，应作为风格升级另行确认。

## 统一制作规格

1. 角色主体与边框分离：人物原稿建议1024方形，透明外部；裁切后头部占头像约60–70%。界面派生96/192px；选人图再按显示尺寸导出。不要直接把原稿全部下发手机。
2. 道具与物品：物品主体原稿建议1024方形、透明外部；手机约96/192px衍生图。六边形框、消耗、中文名与状态在代码里绘制，不让AI生成文字。
3. 房间与地图：完整横向场景原稿约1536×1024；手机先尝试600px宽WebP，保留主体和标题安全区。地图封面只用于选图；两图11+10房间真实拓扑不变。
4. 模块关键图：每模块一幅独立主体插图，可与角色/道具图合成；轻量横向原稿，模块内使用小尺寸衍生图。不能把按钮、日志、骰面、血点、私密内容烘焙进图。
5. 构图统一：潮冷雾、粗笔触、灰黑材质、骨白边缘、少量旧黄铜；人物和物体的轮廓不能被背景吞掉。禁Logo、水印、官方截图和描摹。
6. 每图验收：原图看结构、缩至48/64/96px看识别；灰度看轮廓、透明边缘看残留、对实际房间底色看对比。手机文字/图标对比与热区单独检查，不能由“图好看”代替。

## 独立任务的中英文提示模板

每次只生成一个主体，把上表的具体特征代入；中文或英文均可，先固定原创风格参考再批量。不要把13名角色要求塞进同一张合照再当13个独立资产。

**中文：**

> 为私人中文恐怖桌游创作一幅原创[主体]素材。[具体辨识特征]。潮冷雾林、粗笔触半写实、炭灰材质、骨白边缘刻线、少量旧黄铜；主体清楚，小尺寸不丢轮廓。保持已审定原创样本的光向与笔触。构图：[头像头肩/孤立物品/横向环境/模块关键图]。背景：[透明外部/完整场景]。不要文字、Logo、水印、数值、UI按钮或官方画面；不复制或描摹既有角色立绘和图标。只输出独立素材，框和状态交给代码。

**English:**

> Create one original [subject] asset for a private Chinese horror tabletop game. Distinguishing features: [specific silhouette, clothing, object structure]. Cold damp fog, rough semi-realistic brushwork, charcoal materials, bone-white rim accents, restrained tarnished brass. Maintain the approved original reference's lighting and brush density. Composition: [head-and-shoulders portrait / isolated item / landscape environment / module illustration]. Background: [transparent exterior / complete environment]. Keep the subject readable at small UI size. No lettering, logo, watermark, numbers, buttons, official artwork, tracing, or copied franchise iconography. Export the subject separately; UI frames and states will be rendered in code.
