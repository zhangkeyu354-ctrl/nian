## 尚未覆盖

- 结算的错峰仅作用于当前处于结算阶段的仪表展示。服务器立即推进阶段时，仪表跟随新阶段，不延迟可交互流程。
- 暗置以座位角标显示张数。桌面独立牌背和每个提交动作的独立加载状态尚未实现。
- 抽牌动画从座位出发，依赖牌库减少且手牌增加的快照变化。抽到即打等手牌不增加的情况不会触发该动画。
- 未做实体中低端手机性能测量，也未逐一测量全部交互热区。
- 使用现有素材，无新增美术需求。


## 实际验证

- `npx vitest run packages/menace`：6 个测试文件，109 项通过，0 项失败。
- `npm run build`：构建成功。构建器提示全站包体大小和插件耗时。
- `scripts/verify-ta-audit.ts`：使用临时副本保留改前截图，执行四种视口的九个画面与联机检查。36 张截图的页面横向溢出为 0，20 次阶段操作均得到服务端确认。详见[浏览器记录](polish/after/audit-results.json)。用普通点击进行操作，包含短屏投票区向下滚动后点击弃权。验收未使用强制点击。
- `scripts/verify-ta-browsers.ts`：以移除两处强制点击的临时副本运行。两次运行均在最后的刷新步骤超出 9 秒导航等待，退出码均为 1。独立验收脚本另行验证了刷新、断线重连、人机推进、再开一局和服务器重启恢复。
- 首轮扩大检查角色能力流程时，否决权、强制征收、打捞作业的存档断言失败，矫健身手的确认点击超时。本轮未将这些用例计作通过，未改规则或角色能力流程。
- 首轮审图发现短屏卡名被裁切、身份遮挡能力区、离线代操作遮住圆桌。修复后查看了三个指定尺寸各九张页面截图，核对手牌、圆桌、规则与详情覆盖层。截图使用浏览器的减少动态效果模式，静态截图无法证明帧率或每个动画时点。
