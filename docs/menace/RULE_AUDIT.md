## 本轮裁定与实现

下表优先于前面的原始对照及下方历史建议。

| 编号 | 采用的规则和实现 |
| --- | --- |
| 1 | 第 2 处伤触发模范生、坚定者窗口。轮末从任务领袖开始顺时针逐人结算死亡及其技能。 |
| 2 | 氧气归零优先终局。已有克难者救氧窗口优先处理；救回后继续。满能量到轮末判定，无存活内鬼时安全线仍为第 14 格及以上。 |
| 3 | 胆小鬼按身份卡面，规则页明确优先级。复仇者需要另一名玩家被杀。 |
| 4 | 否决先于守卫；被否决的牌不触发首张效果、不消耗待复制；最后一张必须否决。 |
| 5 | 打捞保留 0–2 张；请求效率少于两张不可发动。应急治疗、自我修复要求目标有伤，多张由发动者选。 |
| 6 | 安全检查由发动者选择第几张，只告知所选牌；强制征收拒绝空牌库。 |
| 7 | 出牌共用限制和肺部穿刺，抽牌共用狂乱处理。狂乱遇禁止出牌时，主动抽牌拒绝，强制抽牌保留牌库顶。被委任者没有合法台面上或台面下行动时跳过。 |
| 8 | 脑震荡由持有者自行选择弃到两张。英文原卡有随机字样，此处使用本次裁定。 |
| 9 | 英文原卡为官方图集牌号 111。文字要求任务领袖收集台面下行动牌时随机弃一张，然后判断是否需要艾玛，未限定伤牌持有者就是领袖。按本次裁定仍仅在持有者任领袖时执行。 |
| 10 | 热情帮手询问包括只需弃牌的能力，仅免氧能。有样学样使用本轮座位来源记录，排除自己。旧存档缺来源时不会仅凭能力名称允许复制。 |
| 11 | 被放逐的克难者仍不能救氧。没有其他存活邻座时个人目标达成。 |
| 12 | 矫健身手在实际暗置前仅向发动者预览，狂乱禁止查看时直接暗置。英文狂乱卡允许查看，中文版禁止查看，此处保留项目已采用的中文卡面。 |
| 13 | 装备征收改称整装备战；倒带写明在结算结束时取牌。 |

## 历史裁定建议

| 问题 | 默认建议 |
| --- | --- |
| 两伤与身份打断、多人同轮死亡 | 第8页明确轮末两伤死亡，并允许此前继续行动或治疗。建议保留轮末死亡，确认模范生和坚定者是否于第2张伤害到来时处理，以及同批死亡和连锁的排序。不要把两伤改成即时死亡。 |
| 同时获胜、安全线边界 | 建议遵从第8页的氧气归零立即判负、满能量轮末检查、无存活内鬼时须超过70%。当前安全线用大于等于14格，且任务栈耗尽后才检查。先确认既有版本对「越过」和连锁中止的裁定。 |
| 胆小鬼与复仇者 | 建议胆小鬼以规则书存活判胜为默认，进阶另核个人目标；卡面转阵营建议保留为版次差异供选择。复仇者个人目标请确认自己死亡是否计入。 |
| 复制、否决、守卫 | 建议先明确被否决牌是否消耗「首次揭开」和待复制，以及多人打断先后；未裁定前保留当前顺序。 |
| 目标及不完整支付 | 建议打捞不足两张取现有全部，请求效率要求有两张；无伤不应支付治疗。明确伤牌选择者、看多张暗置时谁选，以及空牌库征收。 |
| 嵌套与伤势 | 建议所有实际出牌共用状态锁定、断肢和肺穿刺检查，所有实际抽牌共用狂乱替代，并确保没有牌面私密泄露。先明确强制出牌遇禁止时如何处理。 |
| 辐射灼伤、脑震荡 | 建议按英文原卡再确认辐射是否只在持有者任领袖时生效。脑震荡卡面未写随机，默认建议让持有者立即自选弃至两张。 |
| 热情帮手、有样学样与克难者 | 建议核实免除费用是否包含弃牌、复制来源应如何追踪，以及放逐后是否仍可救氧。 |

伤害数量维持规则书 15 张。英文模组牌堆也是 15 张，中文存档牌堆 16 张。中文 16 张中有重复皮肉伤牌号，另有两张不同牌号的断肢，不据模组调整网站数量。
