## 验证

- `npx vitest run packages/menace` 通过 113 项，0 项失败。
- `npx tsc --noEmit -p .` 与 `npm run build` 通过。
- `npx tsx scripts/verify-ta-flow.ts` 通过指定流程。视频用普通点击启动，未使用强制点击。
- `npx tsx scripts/verify-ta-flow.ts --full` 使用一名浏览器玩家和人机，从选角走到结算。4 人局普通点击 67 次，8 人局 145 次。[4 人](flow/整局-4人-结算.png) · [8 人](flow/整局-8人-结算.png)

- `npx tsx scripts/verify-ta-audit.ts --abilities` 最终通过 18 名角色的 36/36 个技能槽，覆盖 28 种独立能力。脚本逐项检查发动记录、即时问答和界面提示。[逐项浏览器结果](flow/ability-results.json)

## 验证边界

- 视频验证使用 Windows 的 Edge 和 390×640 视口，并检查了实际视频节点属性。未在实体 iPhone 的微信内置浏览器运行。
- 资源提示按每份服务端更新的净变化生成，同一次更新内互相抵消的数值不会分别显示。客户端从当前存档接入时，不回放接入前的历史演出。
- 角色浏览器审计针对能力发动、即时问答、存档和提示。跨回合触发、所有目标组合及每个玩家视角没有逐一做浏览器穷举。
