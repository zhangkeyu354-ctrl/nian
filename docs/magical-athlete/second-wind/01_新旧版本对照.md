# 当前实现与 Second Wind 对照

核对日期：2026-10-25。基线 `f356900`；工作分支 `codex/ma-second-wind-research`。本轮没有改线上版本、推 main 或部署，也没有重建桌游合集。

## 当前源码结论

|项目|实际实现|证据与限制|
|---|---|---|
|版本|CMYK 2025基础版，混入部分2026修订及房规|`racers.ts`明确写2025；不是完整2026逐条核验版，也没有 `rulesetVersion`|
|角色|36名，36名在DRAFTABLE中|完整英文/中文/ID与状态见 `current-implementation.json`；程序内标CONFIRMED不等于本轮重新核验所有新版卡文|
|与2025参考名单差集|缺失0、多录0|按36角色图鉴的稳定ID比较；不同中文译名不当作新角色。Copycat/Copy Cat、Lovable/Loveable为命名别名|
|Second Wind当前角色|0|候选36名与现有基础英文名碰撞0；需新增36，不能重复导入基础36|
|人数|网页和引擎2–8，官方产品2–6|7–8是用户已采用的房规，不能描述为官方人数扩展|
|招募|蛇形选秀或随机发4名|默认draft；基础标准模式分两次蛇形，每次翻2N张。随机选角模式全场不重名|
|双选手|引擎保留2/3人显式double，网页固定standard|double每人8名、每场2名；网页所有人数每场1名是房规。多角色能力包括同玩家的另一角色|
|比赛|默认4场，mild/wild/mild/wild|选手一般只能使用一次；两名冲线结束；能力可能提前终止比赛|
|积分|默认四场都金3银1，房主可按场修改0–20|与新镜像中“后续场次更高分”的叙述不完全相同；精确逐场奖牌数值不能从文字猜测|
|铜分/特殊得分|星星、可爱废柴、西西弗斯等|已存在独立筹码；总分平局并列冠军|
|旧赛道|Mild Mile与Wild Wilds两种|0起点、1–29赛道、30冲线；wild10个特殊格，详见03证据表|
|技能触发|赛前、回合开始/主移动、掷骰、经过、停格、回合末等|`move`与`warp`分离；当前先赛道，再当前玩家及顺时针其他能力；不是通用显式事件队列|
|暂停/恢复|Need + pending + 本单元快照与回答数组|收到选择后重放当前单元；RNG在服务端快照内，非客户端决定效果|
|去重|房间命令列表长度/版本号STALE拒绝|防重复执行，不是带receipt的幂等成功重试。没有命令ID、决定ID或持久化事件游标|
|控制权|Token.owner与pending.player，凭房间token绑定玩家|当前没有交换owner的正式能力；回合以玩家current推进，对Switcharoo/Re-Runner不能直接复用假定|
|持久化|房间参数与命令文件，重启重放|临时文件+rename；Render免费临时盘替换不能承诺存档保留|
|隐私|移除deck/turn/rng/forcedRolls，隐藏他人choices和pending.options|扩展中的秘密骰、未来答案、队列payload还没有生产投影策略|
