# 第六批开发预览：用户裁定（2026-10-26）

来源等级：USER_RULING。以下是用户明确选择的开发预览行为，不是官方规则补充或上线许可。

## Mr. Dice Guy / 骰子先生

六颗骰子没有重复数字时，整组六颗重新掷，直到出现可选的重复数字。不会将本次主移动判为 0。六骰组中的每颗骰子照常受派对扫兴鬼、惊艳者等现有能力影响。

## Spoilsport / 扫兴者

触发取消比赛后：所有人保留已经获得的星星分、技能分；本场不发金银奖牌；扫兴者获得 3 分。已经冲线的记录保留供回放，但不加入本场奖牌或冠军历史。

尚未核实的其他互动仍在待核清单中。香蕉后退经过的规则保持当前实现，留到全部角色验收时统一决定。
