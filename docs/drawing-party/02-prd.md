# 绘画派对 PRD
来源：V1.2研究及01-pressure-test；当前用户已明确实施授权。
目标：手机浏览器3–8位真人两款游戏闭环，同一服务器/局域网；现有游戏不变。
REQ-001 大厅两入口，建房/昵称/邀请链接/3–8人数/全员准备，变人数撤销准备。
REQ-002 传话N链，K=N−N%2，奇偶映射；题/画/猜期限、提前提交、服务器草稿到时封存；揭晓逐步、回放/PNG下载，无积分。
REQ-003 伪画家自动原创题、单卧底、两圈单笔、公开画布、只有当前画者可写；讨论、私密投票、并列未抓到、被抓一次猜题、结果/再准备。候选用原创词库18选项以免同义词裁决；猜前可观察，开始选择后藏图。此为标明的线上改编，未宣称完整复刻官方。
REQ-004 服务端按人投影视图，房主无额外秘密；token恢复、幂等操作、限额/坐标验证、截止权威、双标签写租约。
REQ-005 本地草稿缓存+服务端确认；服务重启在配置数据目录仍保留时恢复。Render免费临时盘不可承诺重启不丢，界面如实标注。新增持久服务待另授权，不改部署。
REQ-006 竖屏优先、可选横屏和CSS专注；Pointer/cancel/DPR统一纸面；错误重试/保存状态；最少44px控件。
验收：两款3–8规则测试、协议权限/恢复/重复/截止、实际浏览器完整对局、横竖屏截图、旧测试/typecheck/build。真机未有设备则如实列未验。
Later：真人主持（实体版冲突）、长期云分享、公开画廊。非目标：旧架构重写、部署、使用官方原始素材。
开放：公开授权、长期存储预算、真机体验，均不伪称通过。Ready for groovy-alignment: Yes。
