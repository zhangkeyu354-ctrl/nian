# 横屏画室升级交接

本次按用户手机参考图提升两款现有游戏的美术与动作反馈，并按追加要求优先扩大画布。分支仍为codex/drawing-party，不推送、不部署。

## 试玩

- 传情画意：http://127.0.0.1:3013/?game=tp
- 纽约伪画家：http://127.0.0.1:3013/?game=fa
- 同Wi-Fi手机：http://192.168.0.71:3013/ （仅本地服务，按实际网卡地址；不是公网部署）

绘画阶段右上角“⛶ / 放大画布”收起边栏与装饰，放大白纸；右下角“返回画室”恢复参考图布局。普通横屏保留左右画家；竖屏可以继续玩，并提示横放，不依赖强制旋转。测试服务存档与试玩目录分开，当前使用work/dp-studio-v2-preview。

## 界面与反馈

伪画家：桃红纹理、中央木画架、双侧8位原创头像与编号金属画笔、左侧金色秘密题牌/右侧透明主题牌、黄边计时器、黑色操作提示。菜单集中规则、邀请、音效、全屏与结束本局。

传话：紫色绘本画室、白色宽幅纸面、题目顶栏、工具弹层、青绿提交按钮；揭晓按玩家传话本与页码浏览，保留逐页解锁、逐笔回放、PNG和整链长图。移除了玩法页面长文式堆叠。

动作：本机落笔立即显示实体画笔，抬笔离纸；共享画笔按增量平滑移动；当前画家高亮、阶段提示出现、按钮按压/投票确认、提交盖章和相册换页。音效由用户显式开启，浏览器WebAudio合成，默认关闭；尊重prefers-reduced-motion。

画布固定2:1宽幅纸面；逻辑点仍为1024×1024归一化。显示backing、指针映射、回放、2048×1024导出及整链长图统一比例。渲染用均匀缩放后映射Y坐标，避免横纵笔宽不一致。像素密度最高2。本地第一版正方形试验画作以宽幅重绘，新版本不声称旧纸面截图比例原封不动。

普通844×390横屏，8人测得FA白纸610×305、TP584×292；放大模式实测增长超过15%，画布约占横屏九成宽、高。667×375另验可用。尺寸是模拟浏览器CSS像素，不是物理手机测量。

## 主题投票是实际功能

新增CATEGORY阶段：职业、文具/工具、家具/电器、昆虫、陆栖动物、随机。五类各18词；全员一票或30秒到时，最高票主题采用；平票采用独立服务端随机种子，不从答案位置推断。全员弃权不会卡住。投票中不发送身份、答案、候选猜题词；自己的投票仅自己可见。

后续保留3–8人全部参与、单卧底、两圈一笔、讨论/私密投票、被抓后18选1猜题。仍明确为自动主持线上改编，不宣称实体主持模式或官方数字版完整复刻。素材是SVG/CSS绘制，不把截图做成无法交互的背景。

## 复查

先构建并启动服务，再设置PowerShell环境变量DP_URL：
```powershell
$env:DP_URL='http://127.0.0.1:3013'
npx tsx scripts/verify-drawing-browsers.ts
npx tsx scripts/verify-drawing-studio-eight.ts
npx tsx scripts/verify-drawing-party.ts
npm test -- --maxWorkers=2 --testTimeout=30000
npm run typecheck
npm run build
```

协议脚本每轮新建12房间，勿在正式玩家目录反复压测。下一步以真实手机试玩调整手指遮挡、字号、浏览器栏与弱网；部署仍需用户后续授权。
