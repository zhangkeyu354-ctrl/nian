# 画布遮挡修复与公开投票

本次依据用户明确请求实施已有游戏的UI修复与揭晓流程增补。沿用原产品门槛和画室设计；用户已确认：成功／跑偏／弃权，30秒，成功票多为成功，跑偏多为跑偏，平票意见不一；成功票和MVP／坑货票都公开。不是系统检查文字相等，不新增分数或胜负。

设计基线：每本末页先显示起点→终点，公开判断票结票后由房主进入现有奖项投票。新阶段VERDICT、VERDICT_RESULT。计时、计票、合法值/重复与chain校验由服务端执行。公开投票随提交更新，结票后未投者记弃权；每本结果保存公开票明细。旧存档不伪造历史投票。

画布按钮（保存图、逐笔回放）从纸面移至纸外操作条；提交/猜测控件也在独立区域。依据用户“竖屏更大，横屏不受很大影响”的优先级，新画纸使用4:3：同宽高度增加50%，横屏按可用高度完整容纳，因此宽度会收窄。比例随作品保存，旧作仍用2:1，旋转、重连、缩略图和导出使用同一比例。

使用bug-hunter复现定位、tdd-builder测试先行、develop-web-game实际浏览器验证。无外部美术、无数据库变更、无部署。
