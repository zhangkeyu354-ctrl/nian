# 横屏画室视觉与反馈升级

用户2026-10-22明确要求按两张伪画家手机参考尽量还原，并提升传话的精致度。属于已授权产品的设计迭代，原有四项门槛继续有效，本记录更新设计基线。

视觉主张：伪画家为桃红织纹背景、中央木画架白纸、左右头像与编号实体画笔、左金色秘密牌、右亚克力主题牌、黄色计时和黑色操作提示。传话为紫色放射纹、厚边绘本、奶白纸面、左右绘画工具与青绿完成按钮。素材由SVG/CSS独立绘制，不把用户截图当背景贴图。

信息顺序：阶段/题目→画布→当前行动→其他画家；菜单收起房间、规则、结束与音效，避免网页长文式滚动。所有玩法状态有同一世界观：大厅、主题投票、写题、画画、猜词、等待、投票、观察、猜题、揭晓、结果。

交互主张：实体画笔随落笔移动并在抬笔时离纸；交棒时头像与画笔突出、阶段提示入场；按钮按压、投票选中、提交成功盖章、相册换页。音效由用户开关开启，WebAudio本地合成，不自动播放音乐。尊重减少动态效果设置。

新增主题投票为自动主持改编的明确扩展：五类+随机，每人一票，到时未投弃权，最高票主题采用，平票由服务端独立随机种子选择；全部弃权随机。投票阶段不发送角色与答案。选定后仍保留既有两圈/投票/猜题规则。题库扩至五类各18词。此扩展是为实现参考图操作，不宣称官方规则全部一致。

画布：所有设备固定2:1宽幅纸面（用户追加明确要求手机画布尽可能大），1024归一化坐标保持；实际backing和导出统一2:1，不能CSS单独拉伸。手机横屏100dvh两侧玩家、中间纸面；按钮至少44px。竖屏提供横屏建议，可继续玩，不强制旋转；低高度工具可收纳。绘画不能页面滚动，旋转不能改变笔画形状。
