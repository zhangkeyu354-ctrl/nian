# Design baseline
视觉/UI依据：Gartic Phone绘本式中央纸面、题目顶栏、侧/底工具、完成按钮、相册；Oink伪画家共享画板、明确当前作者、角色独立视图、画展式结算。采用同类布局和交互，原创CSS/几何图标，不复制Logo/品牌插画/代码。用户希望节省另行设计，本次不做营销页。
手机：固定正方形逻辑纸面，竖屏工具在底、横屏靠侧；字16px、按钮44px；黑白画布+传话紫色/伪画家深蓝与金色；颜色额外标序号。主工作区是纸面。
状态：大厅空/加入/准备、题目、画画、猜词、等待、断线保存、提交失败、讨论、投票、观察猜题、选择、结果、逐链揭晓。每态只有一主操作；无权限写时明确当前玩家；等待显示人数/原因。
输入：单pointerId捕获；画布touch-action:none；取消结束当前连续笔；伪画家无撤销/橡皮，传话支持撤销/清空；提交后锁定。文字输入法组合不提前提交。
动效：纸页切换/新笔回放/当前人提示，prefers-reduced-motion关闭过场。导出只用户点击。
架构：新dp前缀模块，不使用DBD纯引擎；低频规则版本与笔画序号分离，服务端有限批量记录后确认，客户端本地排队重发；活动房间状态与图另存目录。
Implementation allowed: Yes，当前用户已明确实施。按tdd-builder开始，缺真机不写通过。
