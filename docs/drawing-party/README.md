## 试玩

在本工作树执行 `npm ci --ignore-scripts`、`npm run build`、`npm run server`。默认3000端口；可用PORT指定。当前隔离预览3012：
- 传情画意：http://127.0.0.1:3012/?game=tp
- 纽约伪画家：http://127.0.0.1:3012/?game=fa
- 同Wi-Fi手机：http://192.168.0.71:3012/ （以服务器实际打印的网卡地址为准；防火墙须允许）

房主选3–8人建房→填写昵称入座→复制邀请→朋友各自入座准备→房主开始。人数必须与入座数相同。建议使用外部语音。离线保留座位；房主离线可接任。局中不能新增替补；到时封存/跳过防卡局；房主可确认结束本局。完成后再来一局，重新全员准备。

## UI使用方式

按用户意图沿用线上产品的工作区结构：Gartic Phone的题目→私人纸面→画猜交替→传话本；Oink数字版的共用纸面→当前作者→私密身份→投票→作品结算。实现为本项目React/Canvas/CSS，无外链嵌入、Logo、官方插画、官方代码。没有声称直接取得官方UI源码或完整实机复刻。
- https://garticphone.com/
- https://oinkgames.com/en/games/digital/lets-play-oink-games/
- https://oinkgames.com/en/games/analog/a-fake-artist-goes-to-new-york/

手机竖屏优先；横屏可用CSS“专注”；无强制横屏依赖。固定1024×1024坐标，显示DPR最高2、PNG2048。触控画布禁止页面滚动，仅捕获一个pointer；取消/离开页面结束当前连续笔。传话可选择8色/4粗细、撤销、清空；伪画家固定个人颜色/粗细、抬手即提交，无撤销。没有橡皮擦、内置语音和正式品牌美术。

## 规则与改编边界

传话计时：题60s、画90s、猜40s；提前提交锁定，最后一人提交或服务器到时进入下一步。未答默认/未画标记到时封存，不伪装成玩家主动完成。揭晓由房主逐页推进；支持单图PNG、整条链长图、逐笔回放；无积分排名。

|人数|画猜步骤K|每人画/猜|每链含初题条数|
|---|---|---|---|
|3|2|1/1|3|
|4|4|2/2|5|
|5|4|2/2|5|
|6|6|3/3|7|
|7|6|3/3|7|
|8|8|4/4|9|

偶数第一步画自己的初题；奇数先传一位再画。每条链的任务作者不重复。3人短链明确是线上改编；不是实体盒装人数声明。

伪画家当前交付**3–8人自动主持改编**：全部参与、随机一名卧底，仅见类别；三类各18个原创常用词；两圈，每位每圈一笔/30s，可跳过；讨论90s、投票30s；私密单票不可投自己，卧底未获唯一最高票则卧底胜；被抓先观察15s，可提前开始18选1猜题/30s，选择阶段隐藏画布；猜中卧底胜，错/超时真画家胜。候选顺序由服务端独立随机偏移，与答案位置无关联。没有增加额外身份和积分。

**未交付真人出题者实体模式**。8人实体版1出题者+7画家，与本版8人全部画画不同；3–4人规则/平衡、18选项、顺序起点、计时均不宣称忠实复刻全部官方数字规则。题库数量和3人博弈质量需朋友试玩评估。

## 技术结构

- `packages/drawing-party/src/index.ts`：纯规则状态机、按人安全视图、规范笔画校验。
- `apps/server/src/drawing-rooms.ts`：独立dp:事件、房间/准备/写连接绑定、服务端截止、笔画日志、快照恢复。
- `apps/web/src/drawing/`：两款共用Canvas、平滑绘制、草稿、回放/导出；不同权限通过props和服务端重复校验。
- 旧代码仅新增大厅入口、懒加载路由、服务器attach，以及dp:stroke独立限流例外；旧引擎/协议/数据库不改，无新依赖。

控制操作带op幂等标识+游戏/阶段/步/轮scope；笔画带id+seq，重发相同内容去重，乱序/冲突拒绝。TP笔画只发本人，不向7位广播；FA只允许当前作者，服务端覆盖笔画ID/颜色/粗细，向全房间发增量。角色/答案/他人投票从服务端视图删除，不靠前端CSS隐藏。token仅发本人，最新加入的同座位连接获得写权限。

每连接25事件/s、单包16KiB、50KB/s；每批最多128点、单画12000点/150笔，FA每回合1800点。坐标有限数值、范围/时间单调、固定颜色/宽度；不接收任意SVG/图片/可执行绘图指令。Socket.IO默认传输帧限制保持旧站设置，16KiB是应用层检查，不等于解析前拦截。20个绘画房间，离线空房24小时清理。

## 保存与恢复的实际保证

客户端即时画，200ms分批，同步IndexedDB绘画模型/待确认队列；收到ACK后移出队列。断网仍能画私人任务；重连在原阶段补传同序号，刷新读取本机草稿。浏览器存储被禁用会显示提示。最近尚未写入本机/服务器的事件、系统强制杀浏览器，不能保证零丢失。

服务端先追加小JSON笔画日志再ACK；低频控制变化原子替换快照后截短日志。重启按revision重放，忽略未完成尾行。只是进程重启恢复，不是硬件断电fsync或跨机器高可用保证。双连接不互相覆盖写。

默认存档为data同级dp-rooms；DP_DATA_DIR可指定。**没有新增Render磁盘或对象存储**。免费临时盘随部署/实例替换可能丢失，页面如实提示；不承诺长期链接分享。只有仍存在的配置存储目录才能恢复。到期已封存阶段不接受迟到草稿；下载作品不依赖服务器永久保存。
