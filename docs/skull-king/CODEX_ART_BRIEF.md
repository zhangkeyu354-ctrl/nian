# 骷髅王 美术需求（给 Codex）
代码已就绪：把图片放进 apps/web/public/assets/skullking/ 就会自动替换现在的 CSS 占位卡，文件名必须完全一致。
- logo.webp（透明底，约 640×360）
- cards/ 下每张 300×436 webp（比例 0.69），整张卡面含边框：
  - green-1…green-14（鹦鹉），purple-1…14（藏宝图），yellow-1…14（宝箱），black-1…14（骷髅旗，王牌最醒目）
  - escape, tigress, king, mermaid-1, mermaid-2, kraken, whale, loot
  - pirate-rosie（女厨子海盗）, pirate-bendt（走私贩出身的大盗）, pirate-rascal（赌徒雇佣兵）, pirate-juanita（有美人鱼血统的占卜师）, pirate-harry（巨人）
风格：手绘质感海盗奇幻卡通、羊皮纸纹理、金色描边；全部原创，不得照搬原版插画；数字放左上与右下（右下倒置），中文名写在卡面下方；手机上 40px 宽也要认得出。
