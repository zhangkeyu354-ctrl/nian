# 骷髅王 · 规则依据与裁定
依据：官方英文规则书（2021 新版，sk_rulebook_optimized.pdf）+ 官方 FAQ（grandpabecksgames.com/pages/skull-king）。
- SK-R1 白鲸生效的墩：只给 14 号牌奖励；角色互吃奖励和战利品结盟不成立（特殊牌被摧毁）。
- SK-R2 克拉肯判"本该赢的人"时，若带头的是克拉肯且后面只有杂色数字，以第一张数字牌的颜色为准。
- SK-R3 灰胡子幽灵带头时，出牌顺序为 幽灵 → 本轮先手玩家 → 另一名玩家。
- SK-R4 平分不加赛（官方规则书未写加赛），同分并列船长。
- SK-R5 海盗技能只在"赢下"时发动；最后一墩只有巨人哈利能用（官方 FAQ）。
- SK-R6 无赖计分差 1 时奖励减半，但战利品必须猜中才拿（官方 FAQ）。
