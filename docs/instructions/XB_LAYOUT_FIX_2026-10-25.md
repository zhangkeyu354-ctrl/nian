# 瞎掰王：手机竖屏布局修复（用户2026-10-25实机反馈）

从最新main（ec71245或之后）开分支codex/xb-layout-fix。只改瞎掰王布局，不改玩法、计分和题库。完成后推送分支、报告提交号并停止；不合并main、不部署。

## 问题
390宽、6人竖屏座位区5+1两行，与提示和按钮占据半屏；舞台只剩一条，终局领奖台被遮挡。xb.css五列和max-height260，与art-v4.css六人起48px头像及100–128px座位高度叠加。

## 目标
390×844下舞台可视高度至少60%；座位、ActionDock、顶栏合计不超过40%。

## 修改
1. 手机竖屏座位为单行横向滑动：flex/nowrap/overflow-x:auto，隐藏滚动条及scroll-snap；每座64px、头像40–42px，仅显示号码、12px省略名和12px分数，总高度≤84px。删除竖屏六人放大和260/296最大高度规则。想想/发言/离线用原有角标光环；计时移到头像环，不增高度；入场定位自己，发言切换定位发言人。
2. 按阶段控制座位：终局、真相/回顾、闭眼、全屏身份隐藏；讨论/指认/扔粑粑等选目标时显示。
3. Dock：主按钮52px；次按钮紧凑，不再一项一行；提示只在自己需操作时显示且最多一行，删无信息量俏皮话；保留iPhone安全区。
4. 终局：领奖台在舞台内可见，前三排名显示头像/名字/分数，其余紧凑列表置于下方可滚动；再来一局留Dock，每轮回顾改为舞台文字按钮。并列排名沿用现有数据。
5. 100dvh总高；舞台内部滚动，顶栏和Dock不随之滚动。
6. 横屏和平板维持原布局，验证无回归。
