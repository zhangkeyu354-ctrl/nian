# 魔法运动员：让玩家看清「谁、做了什么、结果怎样」（交给 Codex）

写于 2026-10-23（Claude）。用户希望 Codex 也独立想办法，**先提方案、再在分支上实现**。

## 1. 玩家反馈（原话整理）
1. 「大家非常快，扔完就一直触发技能然后眼花缭乱」——技能连锁时看不清是谁触发的。
2. 「技能触发的时候直接大屏幕显示 xxx 的技能触发了，本人屏幕显示你的技能触发了，然后再慢慢触发效果」。
3. 「加入摔倒的特效，技能把人摔倒了或者大退了的特效，增强技能触发后的效果显示以及玩家之间的隔差」。
4. 「移动不管是技能的还是主移动，都一步一步慢慢走，哪怕踩到地图上的后退也慢慢的」。
5. 「弹窗太快也会导致眼花缭乱」。
6. 手机上玩（微信内置浏览器居多），屏幕小。

## 2. 已经做了的（线上 / main 已有，请先玩一局再提方案）
- 技能触发：屏幕中央大卡片（本人金色「你的技能触发了！」），停 2.6 秒；发动者在棋盘上放大发紫光。
- 技能连线：发动者 → 被影响者的黄色虚线 + 光圈。
- 小人头顶飘字：「🎲 +5」「箭头 +3」「人气磁铁 −1」「摔倒！下回合不动」等。
- 命中特效：摔倒冒星星、被击退红光冲击、淘汰飞出棋盘、棋盘震动。
- 每格约 0.48 秒逐格走；连锁不再加速；弹窗之间停 0.6 秒；摔倒/淘汰不再弹框。
- 右上角动画速度开关（慢 1.5 倍 / 正常 / 快 0.5 倍），存本机。
- 开跑 3·2·1 倒计时、按住摇骰子、按钮涟漪、得分跳动、目标格提前亮起。

相关代码：`apps/web/src/ma/playback.ts`（动画队列与时长）、`Track.tsx`（棋盘、小人、飘字、连线）、`MagicalAthlete.tsx`（弹窗 Overlay、操作区）、`ma.css`、`sfx.ts`。
引擎事件来源：`packages/magical-athlete/src/engine.ts` 里的 `fx`（roll / power / move{why} / warp / trip / out / finish / chip / podium / champion）。

## 3. 还没解决好的问题（请重点想）
- 一回合里连锁很多时（挪挪蹭步、派对咖吸人、啦啦队长、催眠师……），即使放慢，**事后也很难回想刚才发生了什么**。
- 别人的回合时，玩家不一定盯着屏幕；**回来时不知道刚才谁对自己做了什么**。
- 「谁领先、自己排第几、离终点还有多远」在手机上不够直观。
- 这些都要在**不再继续拉长等待时间**的前提下改善（现在已经偏慢）。

可以考虑的方向（仅供参考，欢迎更好的点子）：回合结束后的「本回合小结」条；「影响到你」的个人提醒；实时排名条；回放刚才一回合；用颜色/图标区分「自己受影响」与「别人之间」的事件……

## 4. 规则与限制
- **不要改规则引擎**的判定（`packages/magical-athlete/src/engine.ts` 只允许新增给界面用的 `fx` 字段，且要补测试）。
- 不改黎明杀机与其他游戏的代码。
- 在分支 `codex/ma-clarity` 上做，不要直接推 `main`，**不要部署**（上线由用户自己点）。
- 完成前必须通过：`npm test`、`npm run typecheck`、`npm run build`，以及 2 人浏览器整局：`MA_PLAYERS=2 npx tsx scripts/verify-ma-browsers.ts`（原版棋盘再跑一次加 `MA_LAYOUT=art`）。
- 手机 390×844 和 390×664（微信）各截图确认，界面文字全部中文。
