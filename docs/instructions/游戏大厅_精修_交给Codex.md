# 游戏大厅精修（给 Codex，Claude 2026-10-23）

用户原话：「我希望 codex 可以精修一下我们的游戏大厅。」
大厅 = 首页 `/`：`apps/web/src/GameLobby.tsx`、`apps/web/src/game-lobby.css`。现在有 8 款游戏。
改前截图：`docs/lobby/before/desktop-1366.png`、`docs/lobby/before/phone-390-full.png`。

## 0. 开工前（必须）
1. 读 `AGENTS.md`、`docs/handoff/协作规则_多个AI共用仓库.md`。
2. `git pull origin main`，**新建分支 `lobby-polish`**，不要直接推 `main`（推 main 会立刻上线，打断正在玩的房间）。
3. 基线：`npm test`、`npm run typecheck`（`apps/web/test/interface.tsx` 两个原有报错除外）、`npm run build && npm run verify:lan-lobby`。

## 1. 只改大厅，不要动
- 各游戏自己的页面、规则、服务器、协议都不改。
- 每款游戏的入口网址保持不变：`/?game=wt|tp|fa|rr|dm|ma|cn`、黎明杀机 `/?online=1`、`/?room=`、`/?hotseat=1`。
- 各游戏房间号长度不同（女巫镇 8 位、绘画派对 6 位、其余 4 位），加入逻辑保持正确。
- 现有 `data-testid`（`game-xx`、`open-xx` 等）保留，测试脚本依赖它们。

## 2. Claude 看到的问题（按优先级）

### A. 卡片不统一，看起来像拼起来的
1. **封面图规格不一**：女巫镇、传情画意、纽约伪画家、魔法运动员是整幅横幅；眼疾手快、请留遗言、黎明杀机、行动代号只有一个小图标。统一成**同样比例的封面区**（例如 16:9、同样圆角、同样高度），每款游戏都有一张完整的原创封面插画。
2. **卡片高度参差不齐**，标题、人数、简介、按钮的位置每张都不一样。统一排版：封面 → 标题 + 副标题 → 人数/类型标签 → 简介 → 开房间按钮，按钮对齐在卡片底部。
3. **简介太长**，有的三行有的四行。每款控制在两行以内。
4. **版权**：行动代号卡片现在的小图像官方盒封面，魔法运动员的横幅也像官方美术。大厅封面全部换成**原创**插画（风格贴近各游戏内页即可），不要用官方盒绘和 Logo 字体。

### B. 每张卡都有一个「有房间号？」输入框，太乱
5. 8 个输入框重复。改成页面顶部**一个**统一的「输入房间号加入」：按房间号长度判断游戏（8 位女巫镇；6 位是传情画意或纽约伪画家；4 位是其余几款）。对应多款游戏时弹出小选择框让用户点选。不新增服务器接口。卡片上只留「开房间」一个主按钮。

### C. 找游戏
6. 加一排筛选标签：**人数**（2 人 / 3–5 人 / 6 人以上 / 10 人以上）和**类型**（拼手速、画画、推理/隐藏身份、团队、竞速）。选中后把不适合的卡片淡化，不要隐藏。
7. 每张卡片加小标签：人数、类型。时长不确定的不要编，写进 `docs/RULE_QUESTIONS.md` 问用户。

### D. 手机
8. 手机上现在整页约 3900 px 高（390 宽）、要滑很久。手机改成**两列小卡片**（封面 + 标题 + 人数 + 开房间），点卡片展开简介。
9. 顶部标题区更紧凑；统一加入框放在顶部，单手能点到。

### E. 质感
10. 顶部做一个有气氛的标题区（沿用现在的深色底 + 柔光），全页标题字体统一，不要每张卡一种字体。
11. 卡片悬停/按下有轻微上浮和阴影；开房间按钮可以沿用各游戏的主色，但形状、高度、圆角统一。
12. 黎明杀机的「同一台设备轮流玩」保留，做成卡片里的次要按钮。
