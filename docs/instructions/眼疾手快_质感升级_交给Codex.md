# 眼疾手快：美术与手感升级（给 Codex，Claude 2026-10-21）

用户原话：「目前感觉质感很差劲……目的是尽量还原原本的模型质感，现在的有点垃圾。」
参考截图（用户提供）：`reference/reflex-race/参考_对局画面.jpeg`、`reference/reflex-race/参考_开始页.png`。
要做到的：**画面质感、物品的立体感和操作手感，和参考截图是同一个水准**。

**版权边界**：参考的是风格（扁平 + 立体侧面 + 粗黑描边 + 两色明暗），不是它的图。5 个物品（沙发、瓶子、书、猫、雪人）都是常见东西，你要自己重新画，**不要描摹、截取或照着参考图的轮廓逐点复刻**，也不要用参考 App 的名字、图标和字体文件。

## 2. 和参考截图的差距（Claude 对比后列的，按优先级）

### A. 物品插画（最重要）
1. **立体感**：参考的物品有明显的厚度——沙发有侧面和扶手的体积、书有书脊和书页侧边、瓶子有高光，都是「正面主色 + 侧面深一档 + 局部高光」。现在的是平面图标，薄。重画成 3/4 视角的块状立体造型。
2. **描边**：参考是粗黑描边（大约物品宽度的 4–5%），外轮廓比内部线条更粗，转角圆润。现在的线太细、内外一样粗。
3. **比例与轮廓**：要胖、圆、块头大，轮廓一眼能认。在 60px 小按钮里和圆盘里放大旋转后都要清楚。猫要能在任意角度认出是猫（参考的猫有坐姿和躺姿，可以给猫、雪人等做不同姿态的变体，但同一物品在按钮上的样子要固定）。
4. **每种颜色都要好看**：每个物品 × 5 种颜色 = 25 种组合都要检查。尤其是**白色**物品在白色圆盘上要靠描边和浅灰阴影分得清；黄色要够饱和；深色侧面不要发脏。为每种颜色定一组「主色 / 侧面色 / 高光色」，不要用一个 shade 套全部。
5. 输出方式：继续用内联 SVG（不加载外部图片），`ObjectArt` 的调用方式 `obj`、`color`、`size` 保持不变。

### B. 画面与布局
6. **圆盘**：参考是大白盘 + 厚奶油色外圈 + 外面一圈更深的紫色阴影环，两个物品**很大**（单个物品约占圆盘直径 40–45%），彼此挨得近、可以轻微重叠。现在物品偏小、离得远。调大并调整 `makeCard` 的摆放范围（保证两个物品都不出圆盘边缘）。
7. **按钮卡片**：参考是白色圆角卡片 + 底部一条紫灰色厚边（按下时卡片下沉、厚边变薄），物品占卡片高度约 80%。现在物品偏小。上排 3 个、下排 2 个居中，这个布局保持。
8. **禁用状态**：点错锁定 / 公布答案期间，现在按钮整体变暗发灰，看起来很脏。改成：卡片保持白色，只降低物品不透明度或加一层浅色遮罩；正确答案绿色描边发光；我点错的那个红底 + 抖动。
9. **计分**：参考左侧是红蓝两色大号数字。我们最多 6 人，保留顶部一排，但数字更大更粗，每人颜色更鲜明；自己那格要突出。得分时那个人的数字有弹跳 +1 动画，扣分时有红色 −1 往下掉。
10. **字体**：用圆润粗体（可以用 Google Fonts 上的开源字体，如 Fredoka / Baloo 2 / 站酷快乐体），中文和数字都要统一的圆润感。标题「眼疾手快」做成参考开始页那样的白字粗黑描边。
11. **首页 / 房间页**：参考开始页是上半部分模糊的游戏画面做背景 + 下面白色大卡片 + 蓝色大按钮 + 橙色返回按钮。照这个结构重做我们的首页和房间页（房间号、二维码、玩家列表、目标分设置都要保留）。大厅首页的游戏盒子图标也换成新画的物品。

### C. 手感与反馈
12. 新图出现：物品「啪」地弹出（缩放回弹约 150ms），不要渐显太久——这是抢答游戏，图出现的那一刻必须清楚。
13. 按下按钮：立即下沉（不等服务器回应）；点对绿色闪光 + 轻震动；点错红色抖动 + 长震动；可加 WebAudio 合成的短音效（「叮」「咚」），设置一个静音开关，默认开。
14. 公布答案：「××抢到了 +1」的提示更醒目，抢到的人的颜色占满提示条；被抢到时其他人的按钮短暂锁住的状态要一眼看得出。
15. 结算页：参考风格的白色大卡片，第一名放大、有简单的彩带/星星动画（CSS 即可）。
