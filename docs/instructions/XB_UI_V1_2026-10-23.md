# 瞎掰王：第一版 UI 定调（v2）

## 0. 已确认

- 保持语音自由讨论，不新增文字解释卡，不加强制提交发言稿。
- 揭晓 = 逐人翻身份。

## 1. 定调「深夜胡扯电台」：热闹、嘴贫、看谁脸不红

- 颜色（CSS 变量，作用域 .xb-world，样式放 apps/web/src/xb/xb.css，不影响全站 button）：底色深墨蓝 #1B1D2B；行动按钮番茄红 #FF5A3C；得分/高亮芥末黄 #FFC83D；说真话薄荷绿 #3DDC97；瞎掰紫 #9B6BFF。
- 材质：便签纸卡片、圆角 14px、柔和投影、轻纸纹；参考 dm/polish.css，不要贴图感。
- 原创"大嘴喇叭"SVG 做 logo 和空状态插画；粑粑用可爱化 SVG。
- 字号：题目 ≥28px，正文 ≥17px。

## 2. 布局（手机竖屏优先）

1. 顶栏 56px：房间号、"第 3/10 轮"、计时圆环、菜单（音效/规则/退出）。
2. 舞台区：一屏只讲一件事。
3. 座位条：横向头像环，显示名字、分数、状态徽章（🎙️发言中 / ✅已选 / 🤔质疑 / 💩被扔）；当前发言人头像放大加光圈。
4. 底部 ActionDock：1 个满宽主按钮（高 52px）+ 最多 2 个次按钮；关键 testid 都放这里。
   横屏：舞台左 2/3，座位条与 ActionDock 右 1/3。

## 3. 各阶段

- 大厅：喇叭插画、"还差 N 人"、房主设轮数、一键复制邀请链接。
- 发身份：翻牌 0.6s，仅自己可见，配图标和一句"你这轮要干嘛"；3 秒后收成顶部小标签，可点开再看。
- 讨论（语音）：题目大卡 + "开麦说吧"；座位条标出当前发言人；计时圆环。不提供文字输入。
- 质疑/指认：点头像 → 头像高亮，主按钮变「指认 X」/「质疑 X」；按住 0.5s 或点两次确认。已选的人只显示「已投」。
- 揭晓（高潮）：屏幕微暗 + 鼓点 → 按座位逐个翻身份牌（每人 0.8–1s），真话绿边加「真的！」章，瞎掰紫边加「瞎掰！」章 → ± 分数字飞入头像 → 被骗的人冒问号 → 分数条增长，名次变化时头像换位。全程 6–12 秒，可跳过。
- 扔粑粑：点头像扔，抛物线飞行，命中压扁，被扔者震动；按钮显示剩余次数；不能扔自己（置灰并说明）。
- 轮换：横幅「下一位：X」2 秒。
- 终局：领奖台 + 称号（最佳瞎掰王 / 最容易上当 / 粑粑收集者）+ 每轮回顾 + 再来一局。

## 4. 操作反馈（硬性要求）

- 点击 100ms 内有反馈（缩放 0.96）；服务器确认前转圈，禁止重复点。
- 被拒绝：按钮抖动 + 中文具体原因。
- 音效复用 drawing/feel.ts，默认开、可关；震动用于被扔中、轮到你、得分。
- 计时颜色绿→黄→红，最后 10 秒数字放大。
- 轮到你：ActionDock 发光 + 顶部横幅；没轮到你：写明"等待 3号 小王…"。
- 断线时顶部黄条"重连中…"；空状态配插画和一句人话。
- 遵循 prefers-reduced-motion；对比度 ≥4.5:1；点击区 ≥44px；真假要配图标或文字，不只靠颜色。

## 5. 验收

- npm test、typecheck、verify:replays、verify:mobile-interfaces，加 3/6/10 人整局和其他游戏回归。
- 截图放 docs/xiabaiwang/ui-v1/：390×844 和 844×390 两种尺寸，每个阶段各一张，另加揭晓 3 张、扔粑粑、终局、断线条。
- 无横向滚动，10 人长名字不溢出。
- 写交接到 docs/handoff/ 和 docs/xiabaiwang/README.md，报告后停止：不推 main，不部署。

计分不改，等用户裁定。
