## 中文本地化原则（用户 2026-10-31 要求：做适配中国玩家的版本）

- 题卡/量表两端词：外国原版的题目逐条翻译成简体中文；只在外国才懂的题（外国名人、外国节目、外国俚语、外国地名常识）换成中国玩家熟悉的同类内容（同样难度、同样的好笑点）。每条记录：原文、直译、本地化版本、改动原因、类型（直译 / 改写 / 替换）。
- 本地化题卡放 `packages/naodong-scale/data/cards.zh.json`，先做成审核页（照瞎掰王词条审核页格式，按类型分组），**用户审核通过才接入引擎**。题量至少与原版相同；原版题不够时可补原创题，标「原创」，同样走审核。

## 2. 引擎（阶段 2）
- 纯函数、种子随机、每张卡唯一 ID。每个命令带 `seq`，重复幂等；非法返回**具体中文原因**（例：「你是本轮队长，不能回答」「已锁定，等待其他人」「刻度只能在 0–10 之间」——按真实规则改写）。

## 4. UI（阶段 4，照做，不自由发挥）
### 4.1 定调
- 官方美术为主 + `dm` 精修同档质感（材质光影、柔和投影、无默认 HTML 按钮、无纯色方块）。CSS 变量作用域 `.nd-world`。笑点在大家的回答，所以画面要给"听人说"让位：舞台区大、文字少。
### 4.2 布局（手机竖屏 390×844 优先）
- 顶栏 52px：房间号、「第 3/N 轮」、计时圆环、菜单（音效 / 规则 / 得分表 / 退出）。
- 舞台区：当前阶段唯一主角（题卡大字 ≥28px / 量表 / 揭晓）。
- 量表（若游戏有刻度）：整宽、刻度数字 ≥15px、可拖动指针 + 点刻度两种方式；指针移动有吸附与轻震动；两端标签大字。
- 座位条：头像、名字、分数、状态徽章（🎙️回答中 / ✅已锁定 / ⏳思考中 / 🔌断线）。
- ActionDock 64px：1 个满宽主按钮（写清动作，如「锁定：7」）+ 最多 2 个次按钮（「撤回」等）。没轮到时灰掉并写「等待 3号 小王…」。
- 横屏 844×390：舞台左 2/3，右 1/3 座位条 + ActionDock。桌面电脑最大宽 1200 居中。
- 全局：可点区域 ≥44px；正文 ≥17px；对比度 ≥4.5:1；无横向页面滚动；最大人数 + 10 字长名字不溢出。
### 4.3 关键画面
- 大厅（「还差 N 人」、房主设置、复制邀请链接、规则速览 3 句话）→ 发题/秘密信息（翻牌，仅本人可见，3 秒后收成顶部小标签，可点开再看）→ 回答（大字提示「开麦回答」+ 计时，**无文字输入**）→ 猜测/锁定 → **揭晓（高潮）**：屏幕微暗 + 鼓点 → 秘密答案揭开 → 每人的猜测逐个落到量表上 → 距离连线与得分数字飞入头像 → 名次变化时头像交换，全程 3–8 秒可「跳过」→ 轮换横幅「下一位：X」→ 终局领奖台 + 按真实统计的称号（最佳嘴替、读心王、最离谱一猜等）+ 每轮回顾 +「再来一局」。
