# 魔法运动员：新角色接入标准（交给 Codex）

写于 2026-10-26（Claude），审阅 `codex/ma-second-wind-research` 首批 3 名（伊卡洛斯、超车手、绊王）之后。
目标：剩下 30 多名新角色，**棋子、卡面、头像、动效、数据统计全部和原版 36 名走同一条路**，玩家分不出哪些是新加的。

## 一、首批 3 名的审阅结果
做得好的（后续保持）：
- 卡面：512×734、同卡框、同字体、同技能条，画风一致。
- 技能实现走了 `fire()` / `trip()` / `move(..., why)`，所以技能大卡片、连线、飘字、摔倒特效、本场数据榜都会自动生效。
- 有开关（房主勾选才混入），关掉时只用原版 36 名；未实现的 sw_ 角色会被拦下。

必须修的：
1. **棋子图尺寸不对**：原版 `tokens/*.png` 是 **约 118×238、裁到人物边缘、脚贴底边** 的透明图；新角色是 256×256、四周留空。棋子框是 1:2 竖条并以「脚」对准格子（`.ma-pawn` 变换原点 84%），方图会显得又小又扁、脚不在格子中心。
   → 重新导出：透明 PNG，**宽:高 ≈ 1:2，裁掉四周空白，脚底贴图片底边**，高度约 238px。
2. **头像尺寸不对**：原版 `portraits/*.webp` 是 **234×172（横向）**；新角色是 320×320。技能大卡片（128×98 cover）、数据榜圆头像会裁到脑袋。
   → 按 234×172 重新导出，脸在画面中上部。
3. **绊王的顺序**：现在是先 `trip(target)` 再 `fire()`，界面会先摔倒再弹「技能触发」。所有新角色统一 **先 `fire()`（技能卡）→ 再产生效果**。
4. 大厅里那段开关 JSX 写成了一行，按项目格式（prettier）整理。

## 二、每名新角色的接入清单（逐条打勾）
**规则（engine）**
- [ ] 只通过 `fire()`、`move(s,c,t,n,main,why)`、`warp()`、`trip()`、淘汰函数、`gainChip()` 改变局面；**不要直接改 `t.pos` / `t.tripped`**（否则没有动画、飘字和统计）。
- [ ] `move` 的 `why` 填技能中文名（界面飘字「技能名 +2」用）。
- [ ] 先 `fire()` 再效果。
- [ ] 需要玩家选「某名选手」时，选项 `value` 用选手 id（界面会自动显示头像和技能介绍）。
- [ ] 与现有关键角色的组合测试：山寨猫（复制）、挪挪（蹭步）、巨婴、吸盘鱼/派对咖（同时到达）、较真怪、香蕉、狂野赛道箭头/石头。
