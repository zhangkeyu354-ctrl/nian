# 瞎掰王 UI v3：新手引导 + 语音阶段辅助 + 整体打磨

先执行git push origin codex/xiabaiwang（只推分支，不动main），推完报告提交号。在e722a4d基础上做，计分不改。完成后推分支、报告并停止：不合并main，不部署。

## A. 新手第一局
- 第一次进房：3页滑动教学（身份是什么／怎么瞎掰／怎么得分），可跳过，记住已看过（localStorage + try/catch）。
- 第一次当想想、老实人、瞎掰人时，各弹一次气泡提示，告诉他此刻该干什么。
- 老实人看答案时：答案卡全屏，倒计时9秒，配“假装在想”的提示，并提醒其他人也在同时点屏幕（所有人统一显示「闭眼中…」画面，防止从动作看出谁是老实人）。

## B. 语音讨论辅助（不加文字输入）
- 想想可以点头像「点名」，被点名的人屏幕出现「轮到你说」横幅并轻震。
- 每个人的发言计时条（可选：房主设每人30／60秒或不限）。
- 想想有一个「小抄」区，可以给每个人打标签（可疑／像真的／？），只有想想自己看得到，揭晓时公开展示，增加笑点。

## C. 揭晓后的回味
- 揭晓完显示「本轮真相」卡：题目+真实解释+来源，所有人可看，可左右滑动查看本局已出过的题。
- 「最离谱瞎掰」投票：揭晓后所有人可点一个人送👑（不计分，只计入终局称号）。

## D. 打磨检查
- 统一间距系统（4／8／12／16／24），统一圆角和阴影层级；检查所有页面不混用。
- 文字层级只用4种字号。
- 声音：统一音量响度，最响的音效不超过提示音的1.5倍；加总音量滑杆。
- 10人、长名字（8个汉字）、最长题目、最长解释，都在360宽手机上不溢出。
- 加载与切后台回来：状态正确，没有重复播放动画。
