# 瞎掰王：彻底恢复原版玩法（用户 2026-10-24 要求）

用户原话：这个游戏就是“一个冷门词，大家去解释、去猜”。当前版本把题目做成了“为什么”问答题，偏离原版，必须彻底改正。规则依据：台湾繁体版《9upper 瞎掰王》（龐奇桌遊、2E愛玩芝麻事规则介绍）。

## 1. 原版一轮流程（引擎和界面都严格照此）
1. 身份：1 名想想（公开）、1 名老实人、其余为瞎掰人（老实人和瞎掰人身份保密）。
2. 出题：题卡正面只有一个冷门词，所有人都能看到。
3. 闭眼9秒：所有人的屏幕统一显示「闭眼中」画面；只有老实人的屏幕显示这个词的真实解释。
4. 解释：除想想外，每个人按座位顺序轮流用语音说“这个词是什么意思”。老实人照实说，瞎掰人现场编。想想可以追问，其他玩家之间也可以互相质问。
5. 「公三小」：想想在讨论过程中可以打给一名玩家（每轮1次，房规HR-XB-02）。
6. 指认：想想选出一个他认为是老实人的玩家。
7. 揭晓与计分：保持现行e722a4d的计分不变（初始3分、难度分D、公三小±1/−3、允许负分）。
8. 想想传给左手边的下一位，重新发身份、换新题。

## 2. 题库全部重做
- 删除现有160道问答题（topics-v1.ts、topics-v2.ts中的全部题目）。
- 新做160个词条，难度64/64/32，沿用现有主题分类。
- 题面：只写一个词或名称，2–8个字，外语词附原文。不写问句，不加任何提示。例：「garum」「洛阳铲」「蚁浴」「biscotti」。
- 背面：用1–2句解释“这是什么”，附一个可核对的来源链接。
- 选词标准：大多数人没听过，但含义真实、具体、有趣；不能从字面直接猜出意思；拿不准的不收。
- 新增测试：题面不能以“？”结尾，不能包含“为什么/是什么/怎么/吗”，长度不超过12个字，题目之间不能重复。

## 3. 界面配合原版
- 题目卡只显示词条大字，“本题D分”放在角落；标题改为「这是什么？」。
- 座位条标出“轮到谁解释”，顺序按座位走，跳过想想；想想可以点头像追问。
- 闭眼画面在所有人手机上完全一致，防止从屏幕动作看出谁是老实人。
