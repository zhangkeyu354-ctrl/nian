# 汽水走私犯 Soda Smugglers：给 Codex 的总指令（Claude 2026-10-27）

严格照抄网站已有标准（AGENTS.md、docs/instructions/RK_MASTER_2026-10-25.md 的格式与要求）。冲突时以本文件为准。

## 0. 总原则（违反任何一条 = 返工）
1. 分支 codex/soda-smugglers，入口 /?game=ss。不推 main、不部署。不改其他游戏的引擎和样式；全站 button 样式的 :not(:where(...)) 排除里加上 .ss-world *（照抄已有写法）。
2. 结构照抄已有游戏：引擎 packages/soda-smugglers/（纯函数 reduceSS(state, cmd)、viewForSS(state, seat)），服务器 apps/server/src/ss-rooms.ts（ss: 事件，服务器 deadline，JSON 快照 SS_DATA_DIR，断线按 token 重连），协议 packages/shared/src/ss-protocol.ts，前端 apps/web/src/ss/，样式只在 apps/web/src/ss/ss.css，作用域 .ss-world。动手前先读 dm-rooms.ts、rk-rooms.ts（若已存在）、dm/Polish.tsx、dm/polish.css、drawing/feel.ts，复用房间、重连、ActionDock、阶段横幅、计时圆环、音效震动，不要另起炉灶。
3. 规则 = 官方原版，不加房规，不凭记忆编。以官方规则书（出版社官网 / BGG 英文规则 PDF）和设计师/出版社在 BGG 的裁定为准。拿不到或有歧义：写进 docs/soda-smugglers/CHECK_REQUIRED.md，标出默认实现，先按默认做，不停下来等。
4. 秘密信息只在服务器：viewForSS 不得泄露别人的手牌、背包内容、秘密声明，直到规则允许公开。日志不打印秘密。
5. 每阶段结束：跑完验收命令 → 写 docs/handoff/SS_阶段N.md（改了什么、命令与真实数字、截图路径、未解决问题）→ 停止并报告。不得声称未实际运行的测试通过。
6. 用户不操作电脑、不想反复改 UI：UI 一次按第 4 节做完并自审截图，看得出的问题自己改完再报告。
7. 美术：同魔法运动员与拉密，可以用官方美术（卡面、角色、Logo、包装盒）；来源逐张记入 docs/soda-smugglers/ASSETS.md，找不到才自绘并标"自绘"。

## 1. 规则调研（阶段 1）
- 找到官方规则书，生成 docs/soda-smugglers/RULE_MATRIX.md：每条写 要点（自己的话）、页码、引擎函数、测试名。覆盖：人数、配件与数量、准备发牌、轮次流程、检查者是谁及轮换、秘密装包与声明、谈判/贿赂及结算、检查与放行判定、罚款/奖励、特殊卡逐张、终局、计分与平局。
- 线上改编只做"自动主持"，不改规则结果：同时秘密操作 = 提交后锁定、全员提交后统一揭晓；口头环节保持语音自由讨论，不加文字聊天；若规则要求可执行的承诺（如贿赂），做成结构化提议（发起/接受/拒绝），写进 CHECK_REQUIRED 让用户确认。
- 生成 ASSETS.md 官方素材清单 → 停，报告（附 CHECK_REQUIRED 问题列表：中文、一问一行、给默认值）。

## 2. 引擎（阶段 2）
- 纯函数、种子随机、每张牌唯一 ID；命令带 seq 幂等；非法命令返回具体中文原因。
- 不变量每次 reduce 后断言：牌/代币守恒、无重复、只有该行动的人能改、viewForSS 不含别人秘密。
- 单元测试覆盖 RULE_MATRIX 每行 + 每张特殊卡；最小/中间/最大人数各 200 局种子模拟打到终局，记录种子。

## 3. 服务器联机（阶段 3）
- 建房、加入、房主设置、开始、断线重连（秘密选择保留）、服务器计时（超时默认动作，规则无规定写 CHECK_REQUIRED）。
- scripts/verify-ss-browsers.ts，package.json 加 verify:ss-protocol、verify:ss-browsers：三种人数整局打完；含非法操作被拒、超时、断线重连、秘密不泄露（检查其他座位页面 DOM 与网络包）。

## 4. UI（阶段 4，照做，不自由发挥）
- 官方美术 + dm 精修同档质感（材质光影、柔和投影、无默认 HTML 按钮、无纯色方块）；颜色用 CSS 变量，作用域 .ss-world。
- 手机竖屏 390×844 优先：顶栏 52px（房间号、「第 3/N 轮」、计时圆环、菜单：音效/规则/退出）；舞台区一次只讲一件事；座位条（头像、名字、分数、徽章 ✅已提交 / 🔍检查者 / 🤝谈判中）；底部 ActionDock（1 个满宽主按钮 52px + 最多 2 个次按钮，关键 testid 都在这里）。横屏 844×390：舞台左 2/3，座位条与 ActionDock 右 1/3。电脑最大宽 1200 居中。
- 可点区 ≥44px；正文 ≥17px；对比度 ≥4.5:1；无横向滚动；10 字长名字、最大人数不溢出。
- 画面：大厅（还差 N 人、房主设置、复制邀请链接）→ 发身份（翻牌仅自己可见，3 秒后收成顶部标签）→ 秘密装包（拖拽和点选都要，提交后锁定）→ 声明 → 谈判 → 检查揭晓（屏幕微暗+鼓点，逐个打开，违禁红光+印章「抓到了！」，清白绿光+「放行」，金额飞入头像，可「跳过」）→ 横幅「下一位检查者：X」→ 终局领奖台 + 按真实统计的称号 + 每轮回顾 +「再来一局」。
- 反馈：点击 100ms 内反馈；确认前转圈防重复；被拒抖动+中文原因；没轮到时主按钮灰并写「等待 3号 小王…」；轮到你 ActionDock 发光+横幅+震动；音效复用 feel.ts，菜单可关，存 localStorage（try/catch）；计时绿→黄→红，最后 10 秒放大；断线黄条「重连中…」；prefers-reduced-motion 关动画；真假不只靠颜色。
- 首页游戏盒用官方包装图 + Logo，标题「汽水走私犯 Soda Smugglers」。
- 自审：截图存 docs/soda-smugglers/ui-v1/（两种尺寸每阶段各一张，另揭晓 3 张、最大人数座位条、终局、断线条、1280×800、首页游戏盒），交接里逐条打勾：无溢出/横向滚动/遮挡；主按钮唯一且文案对；官方图清晰；别人页面看不到我的秘密；与 dm 精修同档。有问题自己修完再重截。
