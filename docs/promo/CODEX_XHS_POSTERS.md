## 0. 网站是什么（海报要传达的）
- 名字：**再来一局**。Logo 在 `apps/web/public/assets/brand/logo.svg`（两张叠牌 + 金色循环箭头），标题字体 `apps/web/public/assets/brand/title.woff2`（只含部分汉字，海报用字不够时用风格接近的免费商用粗圆体，例如站酷快乐体 / 站酷庆科黄油体）。
- 一句话：**和朋友一起在手机上玩桌游的网站，打开网页就能玩，不用下载，不用注册。**
- 卖点（每张海报挑 1–2 个讲，不要全塞）：
  1. 17 款桌游，2–16 人都有得玩（推理、卡牌、画画派对、合作、拼手速）
  2. 一个人开房间，把房间号发给朋友，输入就进来
  3. 手机竖屏就能玩，异地朋友也能一起开黑（配合语音更好玩）
  4. 人不够可以加人机
  5. 免费
- 网址：先**不要**把网址印在海报上（之后可能换域名），在画面底部留一条 120px 高的空白区，写「网址见评论区」。

## 1. 尺寸与格式
- 小红书笔记封面 **3:4，1080×1440 px**，PNG，每张 ≤ 2MB。
- 安全区：四周留 60px；**底部 200px 内不要放重要文字**（小红书会盖标题和点赞栏）；右上角 160×160 避开。
- 中文为主，字要大：主标题字高 ≥ 90px，副标题 ≥ 46px，正文 ≥ 34px。手机缩略图里也要一眼看清主标题。
- 每张图文字不超过 30 个字（主标题 + 一句副标题 + 最多 3 个短标签）。

## 2. 素材规则（重要）
- **不要**把原版游戏封面、原版卡牌图、出版社 Logo 当海报主画面或拼贴墙。宣传是公开商业用途，原版美术只允许出现在「网站真实截图」里，而且截图要小于画面的 40%。
- 可以用：我们自己的 Logo、网站真实截图（首页卡带墙、反转王牌牌桌、骷髅王、绘画游戏画面等，自己用 iPhone 13 竖屏截）、自己画的插画（朋友们围坐、手机屏幕、骰子、扑克牌、桌游配件这类通用元素）。
- 截图放进手机外框（简洁的圆角手机样机，不要写品牌名）。

## 3. 风格（去 AI 味）
- 和网站一致的调子：深色木桌 / 暖光 / 金色点缀；或明亮版本：米白底 + 网站的四个品牌色（玫红 #e2397d、青 #2bb3c0、金 #f2b544、绿 #6cc24a）。
- 干净的色块、柔和渐变、细而少的轮廓线、一个视觉焦点、留白充足。
- 禁止：粗黑描边、排线、噪点、纸张/毛毡纹理、到处发光的粒子、堆满小物件、塑料感 3D、过度锐化、AI 生成的变形手指/乱码文字。画面里所有文字都要用真实字体排版，不能让生图模型直接生成文字。
- 人物（如果有）：简洁扁平插画，不画写实人脸，不画名人或已有动漫角色。

## 4. 要做的 8 张（每个方向 2 张，构图不同）
A. **「今晚组局」氛围型**：几个朋友各自拿着手机围坐（或在不同的房间里视频连线），中间是飘起来的卡牌和骰子。主标题例：「异地也能一起玩桌游」/「今晚，再来一局？」
B. **「产品展示」型**：1–2 台手机样机展示真实截图（首页卡带墙 + 某个游戏画面），旁边 3 个短标签：「17 款桌游」「不用下载」「房间号一键加入」。主标题例：「把桌游店装进手机里」
C. **「游戏清单」型**：用自绘的小图标（不用原版封面）把游戏按类型排成清单：推理 / 卡牌 / 画画 / 合作 / 手速，每类写 2–3 个游戏名。主标题例：「17 款桌游任你挑」「聚会冷场救星」
D. **「三步上手」教程型**：① 开房间 ② 发房间号给朋友 ③ 开玩，每步配一个手机界面小截图。主标题例：「3 步和朋友开一局」
