## 当前原创内容用语（用户最新指令）

- 提示文案：开麦回答；状态：🎙️回答中。没有表演、动作或模仿声音任务。
- 题型（type）：说东西排序类 / 说一句话类 / 场景选择类；来源（origin）：原创 / 用户示例。三种类型不是直译 / 改写 / 替换。
- 每题保存 localized.text（题目）、localized.low（1 的一端）、localized.high（10 的一端）；字段沿用审核包结构，不代表外文翻译。
- 题卡不含外文原文、直译、官方题卡编号或对应页码；source.kind 为 ORIGINAL 或 USER_PROVIDED。原版规则术语翻译仍保留上表，但不翻译原版题卡。
- spicy: true 为独立成人玩笑标签，跨三种题型；150 题中 30 题，占 20%；两端仅保留简短程度标准，不提供答案示例或旁白备注。使用「普通 / 放开」称呼内容尺度，普通只发非 spicy 题（此为后续功能，本阶段未接入）。
- 审核状态：保留 / 删除 / 修改；审核源文件可保留 DRAFT；用户本轮「继续下个阶段」授权的 79 道另存批准快照，今后草稿不自动改为引擎已批准。
- 全队进度 / 团队失误标记 / 全队成功或失败：替代个人分数、得分表和个人领奖台。娱乐称号不排名。

繁体规则用语转换仍适用：評量員→队长，指示物→标记，遊戲圖板→游戏垫板，麥克風→麦克风。参考 [2Plus 官方中文产品页](https://2plus.com.tw/product/q086-top-ten/)，不是题卡内容来源。
