1. 结算按钮在两种配色的实际浏览器渲染中有可见文字与至少 4.5:1 对比度，四人可点击准备并进入下一局。
2. 服务端 Socket.IO 广播、各玩家快照、观战、重连、错误回复与交换阶段不泄露未公开手牌或本局黑A阵营。
3. T23–T32 的终局、末游余分、独狼口径、30 分转移、零分及剃光头逐条可复现；结算页明确展示账本和剃光头依据。
4. 四个独立客户端完成一整局、结算、正常或剃光头抽还、下一局；现有游戏构建及核心回归通过。
5. 2026-11-24 用户明确允许 Beta 版本直接放到现有游戏网站，入口标注 Beta 并添加公告。合并 `main` 前仍须通过现有网站的完整 CI／联机回归、确认无人对局，保留回滚提交。

- iPhone 与 Android 真机、锁屏/切后台/弱网恢复、触觉反馈。
