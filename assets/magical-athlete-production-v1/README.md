范围：2025 CMYK 基础版；36 名角色、两面棋盘、通用卡背、骰子和标记。制作日期：2026-10-20。

## 对照原版的方式

1. 以供应商公开的 CMYK 原版规则书 PDF 为底图：`How-to-play-MAGICAL-ATHLETE.pdf`。角色卡按 PDF 最终可见画面提取，避免读取被覆盖的旧卡文。具体来源、SHA-256、页码与对象号在 `SOURCE_MANIFEST.json`。
2. 使用原版插画、透明棋子和棋盘图；中文标题、能力文字、技能标签与通用图标以原生 SVG 重排。中文路径已轮廓化，不依赖网络字体或目标设备安装中文字体。
3. 温和棋盘的两半有 9px 重复出血区，按源像素重叠拼接。最终尺寸 3190×975；狂野棋盘 1799×550。没有凭印象增加草地、格子、道路或特殊效果。
4. 已检查附件推荐的中文图鉴：其中的角色画风与 CMYK 零售原图不同，没有用其图片冒充原版。附件推荐的社区联机项目包含自定义赛道和凭记忆写的技能，没有采用其赛道数据。
5. 原版插画署名：Angela Kirkwood；出版：CMYK。此包含原版图像派生资源，不能标为本项目原创生成美术。上轮 `magical-athlete-generated-v1` 的三名原创角色图是不同方向的候选，不应混入这套原版角色图。

## 分辨率边界

规则书内的角色卡位图原生通常约 261×374，棋子通常约 120×239（巨婴、大长腿等不同，见 JSON）。本包保证角色身份和图案来自原版；**不声称插画已变成原生 4K**。中文卡的排字、技能框、所有图标与骰子可无损缩放。512px WebP 卡面是把矢量中文与原图合成后的手机导出，不等于提高原插画的真实细节。

## 棋盘坐标

- `x/y/width/height` 是相对于整图的 0–1 比例；将其乘以实际显示宽高即可定位。
- 起点编号 0，普通格 1–29。跨过第 29 格后越过终点，`finish_threshold=30`；领奖台不是额外可停的一格。
- 第二弯角在第 13 格，供飞艇能力核对。
- 狂野：1、13 星星（+1 分）；5、18、26 摔倒；7 前进 3；11 前进 1；16 后退 3；23 前进 2；24 后退 3。
- 箭头数值按赛道前进方向解释，不能直接按画面的左右解释：底边选手向左前进。
- `*-coordinates.svg` 仅是透明编号验收层；不要把编号层当另一个底图，也不要重复计算图上的效果。
- JSON 是美术定位资料。接入时由独立规则数据决定合法操作，界面不能自己计算技能。

## 与现有项目接合

项目为 React + TypeScript + Vite；资源约定在 `apps/web/public/assets/`。建议将运行时目录复制到 `apps/web/public/assets/magical-athlete/`，以 `/assets/magical-athlete/…` 路径引用。**本包没有执行复制、接线、提交、推送或部署。**

已只读检查 `origin/magical-athlete` 的 `a11126d`：全部 36 个素材 ID、中文名、技能名已对齐 `racers.ts`，包括 `baba_yaga`、`flip_flop`、`huge_baby` 等下划线命名；赛道 ID 对齐 `mild` / `wild`。六种玩家颜色也与 `Track.tsx` 一致。详见 `asset-contract.json` 的分支与提交号。

该分支的 `Track.tsx` 当前是 360×520 的程序椭圆，原版是横长矩形。接入时不能只替换背景而沿用 `pointAt()` 的椭圆坐标；应使用本包的原图 viewBox 与格位 JSON 定位棋子。同格堆叠、玩家颜色、摔倒和当前行动标记仍由界面处理。手机应支持局部缩放/平移或全图查看，不能为了塞进旧画布而扭曲原图。

- 中文卡、英文卡、棋子均使用 `object-fit: contain`；棋子按底部中心锚定，避免裁掉四肢。
- 列表用 WebP、按需加载；只预加载本场参赛棋子、当前棋盘与当前选角卡。不要一次加载预览总图、全部 SVG 与 PDF。
- 棋子画布统一为 256×384，真实内容保留原比例。玩家颜色用外层标记或姓名区分，不改角色原图。
- 摔倒仍是原棋子的状态变化；可翻面/旋转并叠加 `icons/trip.svg`，不能换成另一个角色。
- 复制能力仍用蛋、双胞胎、模仿猫自己的棋子，不能用被复制者的棋子替换身份。
- 奖杯/银章图标不写死四轮的得分；分值由负责规则的 AI 的确认数据叠加，避免凭图片猜测数值。
- 私密选角只向持有者显示正面，其他玩家使用同一张卡背。
- 骰子图片显示服务器给出的真实点数；不能按动画图片确定结果。

## 需要规则负责人核定的唯一发现

`ART-RULE-01 / Sisyphus / p25`：最终可见卡面说主移动掷 6 时“替代移动，传送回起点并失去 1 分”；同页旁注却说“传送后仍有主移动”。本包中文卡按最终可见卡面写，技能书明确保留冲突，**没有代替用户裁定或修改引擎**。

其他特别纠正：双胞胎可以复制任意先前比赛的冠军，不限上一场；兔子最终可见卡文没有“独自领先时额外得分”。
