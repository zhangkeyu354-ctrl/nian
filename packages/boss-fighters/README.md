# @nian/boss-fighters —《魔王试炼：码上开战》规则引擎 v0.2（2026-11-10 暂停点）

放入网站仓库后的位置：`packages/boss-fighters/`。纯 TypeScript，无外部依赖。

## 已完成
- **规则引擎** `createGame / reduce / viewFor`：七阶段回合、伤害即时结算、助攻激活、保护（减到 0 取消附加效果）、闪电/插队行动、英雄倒下立即失败、隐私视图、可回放随机数。
- **全部卡牌**：48 初始、32 进阶（卡框花纹归属，2 张纯数值卡暂定）、41 战利品、27 诅咒、20 黏液、6 种道具。数据来源逐张标注 official / observed / tentative。
- **状态与诅咒**：中毒、惊恐（随机出牌）、麻痹（手牌上限）、着火（逐张选择）；诅咒背面→翻开→本阶段/即时/持续；失物堆与黏液牌。
- **英雄成长**：种族/职业 1–3 级数值与 8 种能力（巨魔、半身人、矮人、精灵、战士、法师、盗贼、德鲁伊）。
- **战役**（`campaign.ts`）：冒险团、按官方内容清单解锁、每关 5 张战利品全队各选 1、每星级最多 1 张、收纳盒换卡、牌组整理（≥20 张）、重打低关的星级上限、神灯永久移除。
- **11 个魔王全部可玩**（插件式，`src/bosses/`）：木偶先生、青蛙王子、灵魂女猎手（复活）、以太龙（空中/地面/尖刺护盾）、石魔像（充能/危险碎片）、三头食人妖（三个头/主导/击晕）、巨触手（6 触手路由）、熔岩王（3 手下/岩浆护盾）、炸弹克精（时间制/炸弹/计时炸弹）、果冻怪（黏液精/分裂/泡泡）、巫毒天后（8 种亡灵手下/两阶段/巫毒人偶）。能力名和说明全部用官方中文。
- **机器人**（协作/随机）：用于平衡模拟和以后的掉线托管；魔王插件提供"战术提示"（避开/优先打的属性），界面也可以复用。

## 测试
`npm test`：41 项全部通过（规则 14、卡牌/状态/战役 17、魔王 10，含 11 个魔王 × 2/3/4 人整局不卡死）。

## 平衡（`npm run sim`，协作机器人，进阶难度，按战役进度配置）
见 `sim_report.txt`。目标：教学 ≥95%、第 1 关 75–85%、2–5 关 60–75%、6–9 关 50–65%、巫毒 40–55%。
目前大致落在范围内或略偏，熔岩王、巫毒天后偏难，炸弹克精 2 人偏易。机器人打法有限，**最终以真人试玩为准**，所有数值在 `src/data/balance.ts`。

## 暂停时的已知待办

2. 简化处：生命并列目标按座位取第一位（官方是玩家选）；既视感/透视面具/祖传玻璃眼自动选最优牌；炸弹克精时间段的着火自动处理；巨触手"喷墨"只遮一次。这些需要界面配合时改成玩家选择。
